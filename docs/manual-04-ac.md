# เมนู 04 ต่อสาย AC ระบบ

**ฉบับ 2.1 · ปรับปรุงล่าสุด 9 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/acsys.js` `js/acart.js` `js/acmicro.js`

ต่อสายตามจุดต่อจริงของอินเวอร์เตอร์ (GRID, BACKUP, GEN, CT, สมาร์ทมิเตอร์ RS485, แบตเตอรี่, BMS) แล้วตั้งค่าการทำงาน ระบบตรวจว่าต่อถูกหรือผิดอย่างไร

**ใครใช้ได้**: ค่าเริ่ม auto (ใบงาน W2)

## ขั้นตอน
1. เลือก **อินเวอร์เตอร์ที่ใช้** (ตัวอย่างต่อถูกจะเลือกรุ่น Hybrid ให้อัตโนมัติ)
2. ต่อสาย: ลากจากจุดต่อหนึ่งไปอีกจุด หรือแตะจุดแรกแล้วแตะจุดที่สอง · แตะสายเพื่อลบ · ชนิดสาย L N PE · DC + / − · L1 L2 L3 · A/CAN H · B/CAN L · CT
3. จัดผัง: ลากกล่องอุปกรณ์เพื่อย้าย (สายตามไปเอง) · แตะกล่องเพื่อเลือกแล้วปรับ **ขนาด** เฉพาะตัวนั้น · **มุมมอง** − / + · **รีเซ็ตตำแหน่งและสเกล**
4. **ตั้งค่าอินเวอร์เตอร์และอุปกรณ์**
   - ไฟเข้าบ้านจากการไฟฟ้า: 1 เฟส / 3 เฟส
   - โหมดทำงาน: Self-use · Feed-in priority · Backup reserve · SOC สำรองตอนมีกริด (เฉพาะ Self-use)
   - มาตรฐานกริด: PEA / MEA / อื่นๆ
   - อุปกรณ์วัดกริด: CT / สมาร์ทมิเตอร์ RS485 / ไม่ใช้ · Export limit และขายได้สูงสุด (0 = ห้ามขาย)
   - CT: ตำแหน่งคล้อง (ถูกต้อง = สาย L ที่จุดต่อกริด) · ทิศลูกศร (Solis: ชี้ไปทางกริด) · **⟲ หมุน CT**
   - มิเตอร์: แอดเดรสและ Baud ของมิเตอร์ ต้องตรงกับที่ตั้งในอินเวอร์เตอร์
   - แบต: ลิเธียม (มี BMS) / ตะกั่วกรด · สื่อสาร BMS: CAN / RS485 / ไม่ใช้
   - เครื่องปั่นไฟ: ไม่ใช้ / ชาร์จแบต / จ่ายโหลด · เปิดใช้ไฟสำรอง (Backup) · เบรกเกอร์ GRID / BACKUP (16–63 A)
5. อ่าน **ผลการตรวจ** แก้จนผ่าน
6. ติ๊ก **นำผลการต่อสายและการตั้งค่านี้ไปใช้ในแท็บ "จำลองการไหลของไฟ"** ถ้าต้องการให้เมนู 10 ใช้ผลนี้

## ตัวอย่างสำเร็จรูป
Hybrid ต่อถูก (ใช้ CT) · Hybrid ต่อถูก (ใช้สมาร์ทมิเตอร์) · ตัวอย่างต่อผิด · ล้างสาย

## ระบบ 3 เฟส
- อินเวอร์เตอร์ 3 เฟส: ผังเปลี่ยนเป็น L1 L2 L3 N PE พร้อมสมาร์ทมิเตอร์ 3 เฟส (สายผัง 1 เฟสและ 3 เฟสเก็บแยกกัน)
- ไฟเข้าบ้าน 3 เฟสกับอินเวอร์เตอร์ 1 เฟส: ต่อ GRID L เข้าเฟสใดเฟสหนึ่ง
- ตาราง **มิเตอร์ 3 เฟส** เลื่อน **เวลา** เพื่อดูกำลังแต่ละเฟส (+ ซื้อจากกริด, − ขายคืน) ใช้โหลดและเฟสจากเมนู 09 และไฟดับจากเมนู 10
- ตรวจ: ต่อข้ามเฟส ชอตระหว่างเฟส ไฟไม่ครบ 3 เฟส มิเตอร์วัดไม่ครบ ต่ออินเวอร์เตอร์ก่อนมิเตอร์ Backup ย้อนเข้ากริด

## อินเวอร์เตอร์ Huawei
ชื่อขั้วตามคู่มือ LUNA2000: แบต BAT+ / BAT− · COM 4 เส้น Enable+ → EN, Enable− → GND, 485A → 485A2, 485B → 485B2 · มิเตอร์ DDSU666-H / DTSU666-H ต่อ RS485A/B → 485A1/485B1 · ไม่มีขั้ว CT และพอร์ต GEN · ตรวจ Enable สลับ RS485 สลับ หรือต่อผิดพอร์ต

## ข้อห้ามสำคัญ
ห้ามต่อพอร์ต **BACKUP** เข้าตู้เมนที่มีไฟกริด · CT ต้องคล้องสาย L ที่จุดต่อกริดและลูกศรถูกทิศ

## ขั้วต่อตามอินเวอร์เตอร์จริงแต่ละยี่ห้อ
เลือกอินเวอร์เตอร์ที่ **อินเวอร์เตอร์ที่ใช้** กล่องอินเวอร์เตอร์จะเปลี่ยนเป็นกล่องต่อสาย (wire box) ของยี่ห้อนั้น: ชื่อขั้ว ลำดับขั้ว กลุ่มขั้ว (ขั้วต่อ AC แบบขันสกรู · ช่อง RJ45 · ขั้วสัญญาณแบบขา) และแถบ **ช่องร้อยสายด้านล่าง** เรียงซ้าย → ขวาตามคู่มือ

## หน้าในเมนู 04
แถบด้านบนเลือกหน้า: **พอร์ตอินเวอร์เตอร์** (ต่อพอร์ต GRID / BACKUP / CT / มิเตอร์ / แบต ตามรุ่น) · **ไฟบ้าน + หลักดิน** (ตู้ 2 ชั้น) · **ตู้ไฟงานโซลาร์ (แยกโหลด / Full backup)**

## ตู้ไฟงานโซลาร์ (แยกโหลด / Full backup)
ผนังติดตั้งมุมมองด้านหน้า ตู้ทุกใบยึดผนัง สายเข้า–ออกด้านล่าง แบตและ PV DC Isolator ต่อด้าน DC ไว้แล้ว ลากสาย AC เอง
- **แยกโหลด (ตู้โหลดสำรอง)**: มิเตอร์ → **ตู้เมน** (เมน 2P · RCBO โหลดทั่วไป · MCB INV ป้อนขั้ว GRID ของอินเวอร์เตอร์) · BACKUP ของอินเวอร์เตอร์ → **ตู้โหลดสำรอง** → โหลดสำรอง (ไฟ ตู้เย็น เราเตอร์) · โหลดทั่วไป (แอร์ ปั๊มน้ำ) ต่อจากตู้เมน
- **Full backup (ทั้งบ้าน)**: มิเตอร์ → **ตู้กริด** (MCB INV ป้อน GRID) · BACKUP → **ตู้โหลดทั้งบ้าน** → โหลดทุกชุด · ต้องตรวจว่าโหลดรวมไม่เกินกำลัง BACKUP ของรุ่นที่เลือก
- ระบบดิน TN-C-S: ต่อฝาก N–G ที่ตู้เมน/ตู้กริดจุดเดียว · บาร์ G ลงหลักดิน · ต่อ PE ของอินเวอร์เตอร์ · บาร์ G ของตู้โหลดต่อถึงระบบดินเดียวกัน (เช่นจาก BACKUP PE) · ห้ามต่อฝากที่ตู้โหลด · N ของตู้โหลดต้องมาจาก BACKUP N เท่านั้น · ห้ามต่อ BACKUP เข้าฝั่งกริด (ไฟย้อน)
- ปุ่ม: **ต่อถูก (เฉลย)** · **ตัวอย่างต่อผิด** · **ล้างสาย** · **ไฟการไฟฟ้า: มีไฟ / ไฟดับ** · **▶ เปิดโหลด** · **ทดสอบไฟรั่ว โหลด 1 / โหลด 2** · **รีเซ็ตเบรกเกอร์** · แตะเบรกเกอร์เพื่อเปิด/ปิด

ผลที่ได้ (จากการรันจริง)
| รูปแบบ | มีไฟกริด | ไฟดับ |
|---|---|---|
| แยกโหลด (เฉลย) | โหลดทั่วไป มีไฟ · โหลดสำรอง มีไฟ | โหลดทั่วไป ดับ · โหลดสำรอง มีไฟจากแบต |
| Full backup (เฉลย) | โหลดทั้งสองชุด มีไฟ | โหลดทั้งสองชุด มีไฟจากแบต |

**ตัวอย่างต่อผิด** ไม่ผ่าน 3 ข้อ: ตู้โหลดรับ N จากฝั่งกริด · บาร์ N ตู้โหลดต่อกับ N ฝั่งกริด · ต่อฝาก N–G ที่ตู้โหลด

## ต่อสายไฟบ้าน (มิเตอร์ → เมน → ตู้ชั้น 1 / ชั้น 2 → เต้ารับ + หลักดิน)
อยู่หน้า **ไฟบ้าน + หลักดิน** ใช้ฝึกต่อไฟบ้านตามผังตู้ 2 ชั้น (สายน้ำตาล **L** · ฟ้า **N** · เขียว **G**) ไม่เกี่ยวกับอินเวอร์เตอร์ที่เลือก
1. สายจากการไฟฟ้าเข้ามิเตอร์ต่อไว้ให้แล้ว ต่อ **L ออก / N ออก** ของมิเตอร์เข้าด้านบนของ **เมนเบรกเกอร์**
2. ต่อด้านออกของเมนเบรกเกอร์ไป **SPD** (L, N) และขั้ว PE ของ SPD ลง **บาร์ G**
3. ต่อด้านออกของเมนเบรกเกอร์เข้า **RCBO** ของ **ตู้ชั้น 1 (ตู้เมน)** และ **ตู้ชั้น 2 (ตู้ย่อย)** · ในตู้ RCBO ป้อนบัสไปเบรกเกอร์ย่อย (MCB) และ N ออกไปบาร์ N ให้แล้ว
4. ต่อ **บาร์ G** ตู้ชั้น 1 ลง **หลักดิน** (แท่ง Ø 5/8 นิ้ว ตาม วสท. ข้อ 2.4.1 · ยาว ≥ 2.4 ม. หัวหลักลึก ≥ 0.3 ม. ตามภาพอ้างอิง · ความต้านทานดินไม่เกิน 5 Ω ข้อ 4.27) และต่อบาร์ G ตู้ชั้น 2 มาที่บาร์ G ตู้ชั้น 1
5. **ต่อฝาก N–G** ที่ตู้ชั้น 1 จุดเดียว (สายจากบาร์ N ไปบาร์ G) ตู้ชั้น 2 ห้ามต่อฝาก
6. ต่อเต้ารับแต่ละชั้น: L จากเบรกเกอร์ย่อย (วงจร 1–3) · N จากบาร์ N · G จากบาร์ G ของตู้ชั้นนั้น

ปุ่ม: **ต่อถูก (เฉลย)** · **ตัวอย่างต่อผิด** (ผิด 3 จุด: SPD ไม่ลงดิน · ต่อฝาก N–G ที่ตู้ชั้น 2 · เต้ารับชั้น 2 ไม่มีสายดิน) · **ล้างสาย** · **▶ เปิดโหลด** (ไฟไหลตามสาย L และ N ไปเต้ารับที่มีไฟ) · **ทดสอบไฟรั่ว ชั้น 1 / ชั้น 2** · **รีเซ็ตเบรกเกอร์** · แตะรูปเบรกเกอร์เพื่อเปิด/ปิด

ผลที่ได้ (จากการรันจริง): **ต่อถูก (เฉลย)** ผ่านทุกข้อ เต้ารับมีไฟ 2/2 มีสายดิน 2/2 · กด **ทดสอบไฟรั่ว ชั้น 1** ไฟรั่วไหลลงสายดิน RCBO ตู้ชั้น 1 ตัด (ไฟวิ่งสีเขียวตามสายดิน) · **ตัวอย่างต่อผิด** ไม่ผ่าน 3 ข้อ กด **ทดสอบไฟรั่ว ชั้น 2** ขึ้นว่าไม่มีสายดิน อันตราย

ระหว่างลาก ป้ายบอกผลก่อนปล่อย: ถูกชนิด · ต่อฝาก N กับ G · L ต่อกับ N = ลัดวงจร! · L ต่อกับ G = ไฟรั่วลงดิน! สายที่ผิดเป็นเส้นประสีแดง งานต่อสายไฟบ้านบันทึกในเครื่องนี้ (ไม่ถูกส่งไปกับงานส่ง)

## ตัวช่วยระหว่างต่อสาย
- เริ่มลากจากจุดต่อ: จุดต่อที่ชนิดสายตรงกันจะมี **วงประ** จุดที่ชนิดไม่ตรงหรือใช้ไม่ได้จะจางลง
- ระหว่างลาก ป้ายข้างนิ้ว/เมาส์บอกทันทีว่าถ้าปล่อยตรงนั้น **ถูกชนิด** (สีเขียว) **ชนิดไม่ตรง** (สีแดง) หรือ **ต่อสายเส้นนี้ไว้แล้ว**
- แตะจุดแรก (บนมือถือ) จะมีป้าย "เลือก … แล้ว แตะขั้วที่สอง"
- **บันทึกการทำงาน** ใต้ผลการตรวจ เก็บการต่อ/ลบสายและการโหลดตัวอย่างล่าสุด 40 รายการ กด **ล้าง** เพื่อเริ่มใหม่ (ไม่ถูกบันทึกในงานส่ง)

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| ตู้ไฟงานโซลาร์: ไฟดับแล้วโหลดสำรองดับด้วย | ตู้โหลดต้องรับ L และ N จาก BACKUP ของอินเวอร์เตอร์ ไม่ใช่จากตู้เมน |
| หาส่วนต่อสายไฟบ้านไม่เจอ | กดหน้า ไฟบ้าน + หลักดิน ที่แถบด้านบนของเมนู |
| ต่อไฟบ้าน: เต้ารับไม่มีไฟทั้งที่ต่อครบ | เบรกเกอร์ตัด (สีแดง) หรือปิดอยู่ แตะเบรกเกอร์หรือกด รีเซ็ตเบรกเกอร์ |
| ต่อไฟบ้าน: ขึ้นว่ายังไม่ได้ต่อฝาก N กับ G | ลากสายจากบาร์ N ไปบาร์ G ในตู้ชั้น 1 หนึ่งเส้น |
| ค่าซื้อ/ขายกลับด้าน | CT ลูกศรกลับทิศ หรือคล้องผิดสาย |
| มิเตอร์ไม่สื่อสาร | แอดเดรส/Baud ไม่ตรงกับในอินเวอร์เตอร์ หรือ A/B สลับ |
| ไฟดับแล้วโหลด Backup ไม่มีไฟ (เมนู 10) | ต่อ BACKUP ผิด หรือไม่ได้เปิดใช้ไฟสำรอง |

ตำแหน่งขั้วในภาพจัดเพื่อการเรียนรู้ ไม่ใช่ตำแหน่งจริงบนเครื่อง ตรวจกับคู่มือรุ่นที่ใช้จริง
