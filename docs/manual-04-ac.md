# เมนู 04 ต่อสาย AC ระบบ

**ฉบับ 1.0 · ปรับปรุงล่าสุด 5 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/acsys.js` `js/acart.js` `js/acmicro.js`

ต่อสายตามจุดต่อจริงของอินเวอร์เตอร์ (GRID, BACKUP, GEN, CT, สมาร์ทมิเตอร์ RS485, แบตเตอรี่, BMS) แล้วตั้งค่าการทำงาน ระบบตรวจว่าต่อถูกหรือผิดอย่างไร

**ใครใช้ได้**: ค่าเริ่ม auto (ใบงาน W2)

## ขั้นตอน
1. เลือก **อินเวอร์เตอร์ที่ใช้** (ตัวอย่างต่อถูกจะเลือกรุ่น Hybrid ให้อัตโนมัติ)
2. ต่อสาย: ลากจากจุดต่อหนึ่งไปอีกจุด หรือแตะจุดแรกแล้วแตะจุดที่สอง · แตะสายเพื่อลบ · ชนิดสาย L N PE · DC + / − · L1 L2 L3 · A/CAN H · B/CAN L · CT
3. จัดผัง: ลากกล่องอุปกรณ์เพื่อย้าย (สายตามไปเอง) · แตะกล่องเพื่อเลือกแล้วปรับ **ขนาด** เฉพาะตัวนั้น · **มุมมอง** − / + · **รีเซ็ตตำแหน่งและสเกล**
4. **ตั้งค่าอินเวอร์เตอร์และอุปกรณ์**
   - ไฟเข้าบ้านจากการไฟฟ้า: 1 เฟส / 3 เฟส
   - โหมดทำงาน: Self-use · Feed-in priority · Backup reserve · SOC สำรองตอนมีกริด (เฉพาะ Self-use)
   - มาตรฐานกริด: PEA / MEA / อื่นๆ
   - อุปกรณ์วัดกริด: CT / สมาร์ทมิเตอร์ RS485 / ไม่ใช้ · Export limit และขายได้สูงสุด (0 = ห้ามขาย)
   - CT: ตำแหน่งคล้อง (ถูกต้อง = สาย L ที่จุดต่อกริด) · ทิศลูกศร (Solis: ชี้ไปทางกริด) · **⟲ หมุน CT**
   - มิเตอร์: แอดเดรสและ Baud ของมิเตอร์ ต้องตรงกับที่ตั้งในอินเวอร์เตอร์
   - แบต: ลิเธียม (มี BMS) / ตะกั่วกรด · สื่อสาร BMS: CAN / RS485 / ไม่ใช้
   - เครื่องปั่นไฟ: ไม่ใช้ / ชาร์จแบต / จ่ายโหลด · เปิดใช้ไฟสำรอง (Backup) · เบรกเกอร์ GRID / BACKUP (16–63 A)
5. อ่าน **ผลการตรวจ** แก้จนผ่าน
6. ติ๊ก **นำผลการต่อสายและการตั้งค่านี้ไปใช้ในแท็บ "จำลองการไหลของไฟ"** ถ้าต้องการให้เมนู 10 ใช้ผลนี้

## ตัวอย่างสำเร็จรูป
Hybrid ต่อถูก (ใช้ CT) · Hybrid ต่อถูก (ใช้สมาร์ทมิเตอร์) · ตัวอย่างต่อผิด · ล้างสาย

## ระบบ 3 เฟส
- อินเวอร์เตอร์ 3 เฟส: ผังเปลี่ยนเป็น L1 L2 L3 N PE พร้อมสมาร์ทมิเตอร์ 3 เฟส (สายผัง 1 เฟสและ 3 เฟสเก็บแยกกัน)
- ไฟเข้าบ้าน 3 เฟสกับอินเวอร์เตอร์ 1 เฟส: ต่อ GRID L เข้าเฟสใดเฟสหนึ่ง
- ตาราง **มิเตอร์ 3 เฟส** เลื่อน **เวลา** เพื่อดูกำลังแต่ละเฟส (+ ซื้อจากกริด, − ขายคืน) ใช้โหลดและเฟสจากเมนู 09 และไฟดับจากเมนู 10
- ตรวจ: ต่อข้ามเฟส ชอตระหว่างเฟส ไฟไม่ครบ 3 เฟส มิเตอร์วัดไม่ครบ ต่ออินเวอร์เตอร์ก่อนมิเตอร์ Backup ย้อนเข้ากริด

## อินเวอร์เตอร์ Huawei
ชื่อขั้วตามคู่มือ LUNA2000: แบต BAT+ / BAT− · COM 4 เส้น Enable+ → EN, Enable− → GND, 485A → 485A2, 485B → 485B2 · มิเตอร์ DDSU666-H / DTSU666-H ต่อ RS485A/B → 485A1/485B1 · ไม่มีขั้ว CT และพอร์ต GEN · ตรวจ Enable สลับ RS485 สลับ หรือต่อผิดพอร์ต

## ข้อห้ามสำคัญ
ห้ามต่อพอร์ต **BACKUP** เข้าตู้เมนที่มีไฟกริด · CT ต้องคล้องสาย L ที่จุดต่อกริดและลูกศรถูกทิศ

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| ค่าซื้อ/ขายกลับด้าน | CT ลูกศรกลับทิศ หรือคล้องผิดสาย |
| มิเตอร์ไม่สื่อสาร | แอดเดรส/Baud ไม่ตรงกับในอินเวอร์เตอร์ หรือ A/B สลับ |
| ไฟดับแล้วโหลด Backup ไม่มีไฟ (เมนู 10) | ต่อ BACKUP ผิด หรือไม่ได้เปิดใช้ไฟสำรอง |

ตำแหน่งขั้วในภาพจัดเพื่อการเรียนรู้ ไม่ใช่ตำแหน่งจริงบนเครื่อง ตรวจกับคู่มือรุ่นที่ใช้จริง
