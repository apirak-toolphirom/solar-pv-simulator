# เมนู 12 จำลองเหตุการณ์

**ฉบับ 1.0 · ปรับปรุงล่าสุด 5 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/events.js`

ลองให้ไฟดับ เมฆบัง ฝุ่นเกาะแผง ต้นไม้หรือตึกบังแสง และเลื่อนวันตามฤดูเพื่อดูเวลาอาทิตย์ขึ้นตก เทียบกับวันปกติทั้งตัวเลขและกราฟ

**ใครใช้ได้**: ค่าเริ่ม auto (ใบงาน W6)

## ขั้นตอน
1. **ฤดูกาลและอาทิตย์ขึ้นตก**: เลื่อน **วันที่ในปี**
2. **ไฟดับ**: ชนิดระบบ (On-grid / Hybrid / Off-grid) · ไฟดับตั้งแต่ · นาน (0 = ไม่ดับ)
3. ติ๊กเหตุการณ์ที่ต้องการ
   - **เมฆบัง**: เริ่ม นาน ความหนาเมฆ
   - **ฝุ่นบังแผง**: แสงที่หายไป (ฝุ่นบาง 3–8% · ฝุ่นหนาหรือขี้นก 15–30%)
   - **ใช้เงาจากผังไซต์** (เมนู 08)
   - **ต้นไม้บังแสง**: ทิศ ความกว้างที่บัง (องศา) สูง ห่างจากแผง แผงสูงจากพื้น เงาตกบน (ทุก MPPT / MPPT 1 / MPPT 2)
   - **ตึก / อาคารบังแสง**: ทิศ สูง ห่าง กว้าง (บังแสงตรงทุก MPPT เต็มที่)
4. **ปิดเหตุการณ์ทั้งหมด** เพื่อกลับวันปกติ

> หน้าจอบางจุดยังเรียกเมนูไซต์และเงาว่า "แท็บ 05" (เลขเดิมก่อนจัดกลุ่มเมนู) หมายถึงเมนู 08

## อ่านผล
- **มุมมองไซต์ Top / Side view** เงาและมุมแสง
- **กำลัง AC เทียบวันปกติ**
- **มุมเงยดวงอาทิตย์และช่วงที่ต้นไม้บัง**
- **พลังงานที่หายไปแยกตามสาเหตุ**
- **เทียบตามฤดู**: ขึ้น–ตก ความยาวกลางวัน มุมเงยสูงสุด kWh ปกติเทียบมีเหตุการณ์

## วิธีคำนวณโดยย่อ
ต้นไม้: เมื่อดวงอาทิตย์อยู่ในช่วงทิศของต้นไม้และต่ำกว่ายอดไม้ แสงตรงถูกบังตามสัดส่วนแผงที่เลือก แสงกระจายยังเข้า · เมฆลดแสงตรงมากกว่าแสงกระจาย · ฝุ่นลดแสงทุกส่วนเท่ากัน · ไม่รวมผลไดโอดบายพาส

## ใบงาน W6
ลองเหตุการณ์อย่างน้อย 1 อย่าง · คำถาม: เหตุการณ์ไหนทำให้ไฟหายมากที่สุด จะป้องกันหรือแก้อย่างไร
