## 1. คีมย้ำหัว MC4 (MC4 Crimping Tool)

### 1.1 ตรวจสภาพก่อนใช้งาน

| # | รายการตรวจ | ผ่าน | ไม่ผ่าน | หมายเหตุ |
|---|---|:-:|:-:|---|
| 1 | ตัวคีมกับไดส์ (ปากย้ำ) ตรงรุ่นกับหัว MC4 ที่ใช้ (MC4 เดิม / MC4-EVO 2 ใช้เครื่องมือคนละแบบ) | ☐ | ☐ | |
| 2 | ไดส์ไม่บิ่น ไม่มน ไม่มีรอยสึกที่ผิวหน้า ไม่มีเศษทองแดงหรือสิ่งสกปรกติด | ☐ | ☐ | |
| 3 | เฟืองล็อก (ratchet) ไม่ลื่น ไม่ค้าง และไม่ปล่อยก่อนย้ำครบรอบ | ☐ | ☐ | |
| 4 | ก้านคีมและแกนหมุน (pivot) ไม่งอ ไม่หลวม ปากคีมปิดสนิทเสมอกัน | ☐ | ☐ | |
| 5 | ปุ่มปรับแรงย้ำ (ถ้ามี) อยู่ในตำแหน่งที่ตั้งไว้ และหมุนได้ปกติ | ☐ | ☐ | |
| 6 | หยอดน้ำมันเครื่องมือเบา ๆ ที่แกนหมุนแล้ว (ตามรอบบำรุงรักษา) | ☐ | ☐ | |

### 1.2 ทดสอบรอยย้ำ (ทำทุกชุดงาน หรือสุ่มทุก 10–20 หัว)

เตรียม: สายโซลาร์ทองแดงชุบดีบุกขนาดเดียวกับงานจริง, เข็ม (pin) MC4, ไม้บรรทัด/เวอร์เนียร์

| # | รายการตรวจ | เกณฑ์ | ผล |
|---|---|---|---|
| 1 | ความยาวปอกสาย | 7.0 มม. (ช่วงรับได้ 6.0–7.5 มม.) — ตรวจกับผู้ผลิต | ______ มม. |
| 2 | ลวดทองแดงเข้าครบ ไม่ขาดหรือโผล่นอกปีกย้ำ | ลวดครบทุกเส้น | ☐ ผ่าน ☐ ไม่ผ่าน |
| 3 | รูปทรงรอยย้ำ ปีกม้วนเข้าแน่นสม่ำเสมอ ไม่ฉีก ไม่แตก | ตามภาพอ้างอิงผู้ผลิต | ☐ ผ่าน ☐ ไม่ผ่าน |
| 4 | ทดสอบดึง (pull test) ดึงเข็มกับสายตรง ๆ ค้างไว้ | ไม่หลุด ที่แรงขั้นต่ำประมาณ 310 N (ตรวจกับผู้ผลิต / IEC 60512 test 16d) | ☐ ผ่าน ☐ ไม่ผ่าน |
| 5 | ตรวจหน้าตัดรอยย้ำ (ตัดตัวอย่าง 1 ชิ้น/ชุดงาน ถ้าทำได้) | ลวดอัดแน่น ไม่มีช่องว่างมาก | ☐ ผ่าน ☐ ไม่ผ่าน |

> ดูแรงดึงอย่างเดียวไม่พอ ต้องตรวจมิติ/รูปทรงรอยย้ำร่วมด้วย

### 1.3 เกณฑ์ตัดสิน

- **ใช้งานต่อได้:** ผ่านทุกข้อในหัวข้อ 1.1 และ 1.2
- **หยุดใช้ทันที:** รอยย้ำหลวมหรือไม่ผ่าน pull test, ไดส์สึก/บิ่น, เฟืองล็อกลื่นหรือปล่อยก่อนครบรอบ, ก้านคีมงอ
- **แก้ไข:** ลองปรับปุ่มแรงย้ำและทำความสะอาดไดส์ แล้วทดสอบซ้ำ ถ้ายังไม่ผ่านให้เปลี่ยนไดส์ (ถ้าถอดเปลี่ยนได้) หรือเปลี่ยนคีม
- ห้ามใช้ย้ำสายงานจริงจนกว่าจะผ่านการทดสอบซ้ำ

### 1.4 หมายเหตุเรื่องอายุใช้งาน

ไม่มีตัวเลขจำนวนครั้งกลางที่ยืนยันได้ ผู้ผลิตแต่ละรายกำหนดเอง บางรุ่นมีรอบปรับเทียบตามจำนวนครั้งที่ย้ำ
ให้ใช้ผลทดสอบรอยย้ำและสภาพไดส์เป็นตัวตัดสิน และจดจำนวนหัวที่ย้ำสะสมไว้เป็นข้อมูลของเครื่องมือแต่ละตัว

## วิธีเพิ่มเครื่องมือ

คัดลอกหัวข้อ `## N. ชื่อเครื่องมือ` ใหม่ต่อท้าย ก่อนหัวข้อ "ตารางบันทึกประวัติ" แล้วระบุ
1. ตรวจสภาพก่อนใช้ (ตัวเครื่อง, ส่วนที่สึกหรอ, ความปลอดภัย)
2. ทดสอบการทำงานหรือผลงาน (ถ้ามี) พร้อมเกณฑ์ผ่าน/ไม่ผ่าน
3. เกณฑ์ตัดสิน: ใช้ต่อ / แก้ไข / หยุดใช้

ตัวอย่างเครื่องมือที่อาจเพิ่ม: คีมตัดสายโซลาร์, เครื่องทดสอบความต่อเนื่อง, เครื่องวัดฉนวน (insulation tester), ประแจทอร์ก, เครื่องมือถอดหัว MC4, สายรัดและอุปกรณ์ทำงานบนที่สูง

## แหล่งอ้างอิง

- Klein Tools 3010CR, Rennsteig Solar MultiCrimp (ตัวอย่างคีมที่ปรับแรงได้/เปลี่ยนไดส์ได้)
