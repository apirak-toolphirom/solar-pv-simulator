# เมนู 02 อุปกรณ์

**ฉบับ 1.0 · ปรับปรุงล่าสุด 5 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/catalog.js` `js/pdfimport.js`

เลือกรุ่นแผง อินเวอร์เตอร์ และแบตที่ใช้จำลอง รุ่นที่เลือกถูกใช้ในทุกเมนู

**ใครใช้ได้**: ค่าเริ่ม auto (ใบงาน W1) · ผู้เรียน **เลือก** รุ่นได้ แต่ **เพิ่ม แก้ไข ลบ นำเข้า** ได้เฉพาะผู้สอน

## เลือกรุ่น
1. ส่วน **แผงโซลาร์**, **อินเวอร์เตอร์ (ยี่ห้อ / รุ่น)**, **แบตเตอรี่** เลือกรุ่นที่ต้องการ
2. รายการแบตแสดงเฉพาะรุ่นที่ใช้กับอินเวอร์เตอร์ที่เลือกได้ เช่น เลือก Huawei Hybrid ระบบเปลี่ยนแบตเป็น LUNA2000 ให้เอง (เลือกยี่ห้ออื่นกลับเป็นแบตเดิม)
3. อินเวอร์เตอร์มีค่า **ระบบไฟ AC** (1/3 เฟส) **จ่ายไฟแต่ละเฟสไม่เท่ากันได้** และ **พอร์ต Backup** (1/3 เฟส) ซึ่งเปลี่ยนผังในเมนู 04

## รุ่นที่ติดมากับเว็บ
- แผง: LONGi Hi-MO X10 650 W · AIKO Stellar A650–A675 (6 รุ่น) · Trina Vertex N 695–720 W (6 รุ่น)
- อินเวอร์เตอร์: Solis 6K และ S6-EH1P6K/8K/10K-L-PLUS · Huawei SUN2000 KTL-M0, KTL-M1, KTL-L1, MAP0
- แบต: Huawei LUNA2000-5/10/15-S0 · Dyness PowerBrick 14.3 kWh · Solis IntelliHome 5/10/16 kWh · LVTOPSUN LVTS-512314-G4/G3
- รุ่นที่ระบุ "ค่าสมมติ" ไม่ใช่ข้อมูลจริงของผู้ผลิต

> Huawei ใช้แบตแรงดันสูง 350–980 V แบต 51.2 V จึงขึ้นเตือนว่าแรงดันไม่ตรง (ตั้งใจไว้ใช้สอน)

## สำหรับผู้สอน: เพิ่มและนำเข้ารุ่น
1. กด **ปลดล็อกผู้สอน** กรอกรหัสผู้สอน (หรือเข้าโหมดผู้สอนที่แถบบน) จะเห็น "โหมดผู้สอน · เพิ่ม แก้ไข ลบ และนำเข้ารุ่นอุปกรณ์ได้"
2. **นำเข้าจาก PDF (datasheet)**: เลือกชนิด (ตรวจอัตโนมัติ / แผง / อินเวอร์เตอร์ / แบต) แล้วเลือกไฟล์ ระบบอ่านในเครื่อง ไม่อัปโหลด ดึงค่ามาใส่ฟอร์มให้ตรวจก่อนเพิ่ม
   - PDF ภาพสแกนอ่านด้วย OCR (ภาษาอังกฤษ) อัตโนมัติ ตัวเลขอาจเพี้ยน ต้องตรวจทุกช่อง
   - อ่านไม่ได้: คัดลอกตารางสเปกไปวางที่ **หรือวางข้อความจาก datasheet** แล้วกด **อ่านข้อความ**
3. **นำเข้า / ส่งออก**: นำเข้า JSON / CSV หรือ **ส่งออกแคตตาล็อกทั้งหมดเป็น JSON**
4. การแก้ในหน้าเว็บมีผลเฉพาะเบราว์เซอร์นั้น ให้ทุกเครื่องเห็นต้องเพิ่มใน `BUILTIN` ของ `js/catalog.js` แล้ว build + push

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| ไม่มีปุ่มเพิ่ม/แก้ไข | ผู้เรียนแก้ไม่ได้ ผู้สอนต้องปลดล็อกก่อน |
| แบตที่ต้องการไม่อยู่ในรายการ | ไม่เข้ากับอินเวอร์เตอร์ที่เลือก เปลี่ยนอินเวอร์เตอร์ก่อน |
| รุ่นที่เพิ่มไม่ขึ้นเครื่องอื่น | เพิ่มในโค้ด `BUILTIN` แล้ว push |
| นำเข้า PDF ไม่ได้ในไฟล์หน้าเดียว | ไฟล์ใน `dist/` โหลดไลบรารีจาก CDN ต้องมีอินเทอร์เน็ต |
