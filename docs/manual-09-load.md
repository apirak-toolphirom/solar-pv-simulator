# เมนู 09 จำลองโหลด

**ฉบับ 1.0 · ปรับปรุงล่าสุด 5 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/loads.js`

ใส่รายการเครื่องใช้ไฟฟ้า กำลัง ช่วงเวลา และเปอร์เซ็นต์ที่ทำงานจริง ใช้ต่อในเมนู 04 (ตารางมิเตอร์ 3 เฟส), 10 และ 11

**ใครใช้ได้**: ค่าเริ่ม auto (ใบงาน W4)

## ขั้นตอน
1. เลือก **ตัวอย่าง** หรือกด **+ เพิ่มโหลด**
2. กรอกแต่ละแถว: **ชื่อ · กำลัง (W) · จำนวน · เริ่ม · หยุด · ใช้จริง (%) · เฟส · ต่อที่ช่อง**
   - เวลาหยุดน้อยกว่าเวลาเริ่ม = ข้ามเที่ยงคืน เช่น 22:00–06:00 · เริ่มเท่ากับหยุด = ทั้งวัน
   - ใช้จริง (%) เช่น แอร์คอมเพรสเซอร์ทำงาน 60% ของเวลา
   - เฟส: L1 / L2 / L3 / 3 เฟส (ใช้กับระบบ 3 เฟส ดูตารางมิเตอร์ในเมนู 04)
   - ต่อที่ช่อง: **Backup** = ต่อพอร์ต BACKUP ไฟดับยังมีไฟ · **กริด** = ต่อตู้ไฟหลัก ไฟดับไม่มีไฟ
3. ดูกราฟ **กำลังโหลดตลอดวัน**

## ใบงาน W4
โหลดอย่างน้อย 5 รายการ (ร่วมกับเมนู 10) · คำถาม: โหลด Backup ที่เลือกมีอะไรบ้าง ทำไมเลือก

## เคล็ดลับ
เลือกเป็น Backup เฉพาะโหลดจำเป็น (ตู้เย็น ไฟส่องสว่าง เราเตอร์ ปั๊มน้ำ) แบตจะจ่ายได้นานกว่าตอนไฟดับ
