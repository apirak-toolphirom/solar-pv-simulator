# เมนู 19 AC Coupling (พอร์ต GEN)

**ฉบับ 1.3 · ปรับปรุงล่าสุด 11 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/accouple.js`

ฝึกต่ออินเวอร์เตอร์ออนกริด **Huawei SUN2000-5KTL-L1** หรือ **ไมโครอินเวอร์เตอร์ Deye SUN-M200G4** เข้าพอร์ต GEN ของ **Deye** หรือ **Solis** Hybrid ติด CT เปิด/ปิดกันย้อน ตั้งค่าเครื่อง Hybrid และอินเวอร์เตอร์ AC แล้วทดสอบวันปกติกับไฟดับกลางวัน

**ใครใช้ได้**: ค่าเริ่ม **ปิด** ผู้เรียนและผู้เยี่ยมชมไม่เห็นจนกว่าผู้สอนเลือก "เปิด" ที่ dashboard (ต้องวาง `Code.gs` ล่าสุดแล้ว Deploy → New version) ผู้สอนเห็นเสมอ

## เลือกระบบ (ใบสั่งงาน)
| ระบบ | Hybrid | อินเวอร์เตอร์ AC | นโยบายขายไฟ |
|---|---|---|---|
| Huawei → GEN ของ Deye | Deye SUN-6K, แบต 10.24 kWh | Huawei 5 kW (แผง 8 แผง 5.2 kWp) | ห้ามขาย |
| ไมโคร Deye → GEN ของ Deye | Deye SUN-6K | ไมโคร 2 kW (แผง 4 แผง) | ขายได้ ≤ 5 kW |
| Huawei → GEN ของ Solis | Solis S6-EH1P6K, แบต 14.3 kWh | Huawei 5 kW | ขายได้ ≤ 5 kW |
| ไมโคร Deye → GEN ของ Solis | Solis S6-EH1P6K | ไมโคร 2 kW | ห้ามขาย |

## ขั้นตอน
1. **ใบสั่งงานและการต่อสาย**: ต่อสายด้วยการลากในผัง · ลาก**ปลายสายอินเวอร์เตอร์ AC** (จุดดำใต้กล่องอินเวอร์เตอร์) ไปวางที่ ตู้เมน / พอร์ต GRID / พอร์ต GEN / พอร์ต LOAD ของเครื่อง Hybrid ระหว่างลากจุดต่อที่วางได้จะขึ้นเป็นวงกลมประ จุดที่ใกล้ที่สุดจะเป็นสีและมีชื่อกำกับ (ถูก = พอร์ต GEN) · ลาก **CT** (วงกลมมุมขวาบน) ไปคล้องสายกริด สายอินเวอร์เตอร์ AC หรือสายโหลด (ถูก = สายไฟกริดที่จุดต่อกริด) · **คลิกที่ CT** เพื่อกลับทิศลูกศร · วางนอกจุดต่อ = ถอดสาย/ถอด CT ออก · ยังตั้งผ่านรายการเลือก "อินเวอร์เตอร์ AC ต่อเข้าที่" "ตำแหน่ง CT" "ทิศลูกศร CT" ได้เหมือนเดิม (ใช้ผลร่วมกัน) แล้วดูผังและเช็กลิสต์
   - Deye: คู่มือข้อ 5.10 อนุญาตให้ต่ออินเวอร์เตอร์ออนกริดที่พอร์ต LOAD (AC couple on load side) แต่เครื่องแสดงกำลังโหลดไม่ถูกต้อง ใบงานนี้ให้ต่อที่ GEN
   - Solis: ต่อที่พอร์ต GEN เท่านั้น (คู่มือข้อ 5.4.3 Step 7)
2. **จอเครื่อง Deye / Solis**: จำลองหน้าจอเครื่องตามคู่มือ กด **System Setup** (Deye) หรือ **SYSTEM SETTING** (Solis) แล้วเข้าเมนูย่อยเหมือนบนเครื่อง ปุ่ม **◀ Back** และ **⌂ Home** อยู่ด้านล่างจอ
   - **Deye**: System Setup › **System Work Mode** (Selling First / Zero Export To Load / Zero Export To CT, Solar Sell, Max Sell Power, Zero-export Power 20 W) และ System Setup › **Gen Port Use** เลือก **Micro Inv Input** แล้วตั้ง Micro Inv Input **ON** (%), **OFF** (%), **AC Couple Fre High** (ค่าเริ่มในคู่มือ 52.00 Hz)
   - **Solis**: SYSTEM SETTING › **STORAGE MODE** (Self-use / Selling first / Off grid, Allow export, Max export power, Export calibration 20 W, Battery reserve ค่าเริ่ม 80%) และ SYSTEM SETTING › **SMART PORT** เลือก **AC couple input** (คู่มือ Solis ไม่มีค่าความถี่ให้ตั้ง เครื่องใช้ Freq-Watt ปรับกำลังอินเวอร์เตอร์ AC)
3. **ตั้งค่า Huawei / ไมโคร Deye**: Huawei มี P(f) / Freq-Watt (เปิด/ปิด) และ Export limitation (กันย้อน เปิด/ปิด) ไมโครมี Zero export (กันย้อน เปิด/ปิด) ช่วงความถี่ลดกำลังของไมโครเป็นไปตามมาตรฐาน แก้ไม่ได้
4. **แดชบอร์ดและทดสอบ**: เลื่อนเวลาทุก 30 นาที เลือกไฟดับ (10:00–15:00 หรือ 18:00–22:00) เมฆ โหลด SOC เริ่มวัน สลับ "กันย้อน" และ "มี CT ที่กริด" ได้ที่หน้านี้ ดูกราฟและ kWh ทั้งวัน
5. **โจทย์หาข้อผิดพลาด**: กด "เริ่มโจทย์หาข้อผิดพลาด" ระบบจัดค่าที่ถูกต้องแล้วใส่ผิด 2 จุด (เช่น ต่อที่ตู้เมน, CT อยู่ที่สายอินเวอร์เตอร์ AC, CT กลับทิศ, ไม่ตั้ง GEN เป็น AC couple, AC Couple Fre High ต่ำเกิน, ไม่ติด CT แต่เปิดกันย้อน, ปิด Freq-Watt ของ Huawei บน Solis) หาแล้วแก้ให้ผ่านครบ "เฉลยจุดที่ผิด" มีให้ดู

## อ่านผล
- **Deye Micro Inv Input** (ตามคู่มือข้อ 5.10): ตอนไฟดับ กำลังไมโคร/อินเวอร์เตอร์ AC ลดลงเป็นเส้นตรงเมื่อ SOC เข้าใกล้ **OFF** ที่ SOC = OFF ความถี่ที่พอร์ต GEN ขึ้นถึง AC Couple Fre High แล้วอินเวอร์เตอร์นั้นตัดออก กลับมาจ่ายเมื่อ SOC ต่ำกว่า **ON** ตอนมีกริดไม่ใช้กลไกนี้ ในแบบจำลองอินเวอร์เตอร์ AC ตัดออกที่ 51.5 Hz (อ้างตารางป้องกัน 81>.S1 ในคู่มือ Deye) ถ้าตั้ง AC Couple Fre High ต่ำกว่านั้น อินเวอร์เตอร์ไม่ตัด แบตเต็มเกิน แล้วขึ้น **Battery OV** โหลดดับ
- **Solis AC couple input**: ใช้ Freq-Watt ปรับกำลังอินเวอร์เตอร์ AC ต้องเปิดฟังก์ชันตอบสนองความถี่ที่ฝั่งอินเวอร์เตอร์นั้นตามคู่มือผู้ผลิต (Huawei: P(f)) ค่า SOC และความถี่ที่ Solis ใช้ไม่มีในคู่มือ แบบจำลองใช้ค่าสมมติ (ลดกำลังที่ SOC 95–100%, 52 Hz)
- **กันย้อน** (ห้ามขาย): ต้องมี CT ถูกตำแหน่งและถูกทิศ ถ้าเปิดกันย้อนแต่ไม่มี CT หรือ CT อยู่ผิดที่ อินเวอร์เตอร์ AC ลดกำลังเป็น 0 ทั้งวัน (ปลอดภัยแต่เสียพลังงาน) ถ้า CT กลับทิศ อินเวอร์เตอร์ AC ยังผลิตเต็มและขายออกกริดทั้งที่ห้าม
- **พื้นที่ขายได้**: ปิดกันย้อน Deye ใช้ Selling First (หรือ Zero Export + Solar Sell) Solis ใช้ Self-use + Allow export (หรือ Selling first)

ตัวอย่างผลจากแบบจำลอง วันปกติ (แบต 50% เมฆ 0%) เมื่อตั้งถูกทั้งหมด

| ระบบ | ผลิตอินเวอร์เตอร์ AC | ขายไฟ |
|---|---|---|
| Huawei → Deye (ห้ามขาย) | 5.7 kWh | 0.0 kWh |
| ไมโคร → Deye (ขายได้) | 16.4 kWh | 25.7 kWh |
| Huawei → Solis (ขายได้) | 33.7 kWh | 36.6 kWh |
| ไมโคร → Solis (ห้ามขาย) | 3.7 kWh | 0.0 kWh |

ตัวอย่างตั้งผิด: Huawei → Deye ห้ามขาย แต่ CT กลับทิศ ขายออกกริด 21.9 kWh · ไมโคร → Deye ไฟดับ 10:00–15:00 ตั้ง AC Couple Fre High 51.0 Hz ตัดไม่ทัน 10 ช่วง (30 นาที) โหลดดับ 2.6 kWh · Huawei → Deye ไม่มี CT แต่เปิดกันย้อน ผลิต 0 kWh ทั้งวัน

## เชื่อมกับเมนูอื่น
- เมนู 15 Solis และเมนู 18 Deye (ขั้นตอน commissioning เครื่อง Hybrid) · เมนู 17 Huawei FusionSolar (อ่าน log ของ Huawei) · เมนู 10 จำลองการไหลของไฟ

## ข้อจำกัดของแบบจำลอง
ชื่อรายการ เมนู และคำอธิบายบนจอเครื่องตามคู่มือ Deye SUN-3/3.6/5/6K-SG04LP1-EU-SM2 (2026-01) ข้อ 5.4–5.10 และ Solis S6-EH1P(3-8)K-L-PLUS V1.3 ข้อ 5.4 ค่าเริ่ม Deye (Micro Inv Input AC Couple Fre High 52.00 Hz, Zero-export Power 20 W) และ Solis (Battery reserve 80%, Export calibration 20 W, Max export 1.1 เท่าพิกัด) ตามคู่มือ ส่วนค่า Micro Inv Input ON/OFF เริ่มต้น (95/100%), Shutdown/Low Batt/Restart (10/20/40%) ช่วงความถี่ลดกำลัง 50.2–51.5 Hz กำลัง แผง โหลด และพฤติกรรมควบคุมเป็นค่าสมมติของแบบจำลอง คู่มือ Deye ระบุว่า Micro Inv Input ON/OFF มีเฉพาะบางเวอร์ชันเฟิร์มแวร์ ชื่อรายการของ Huawei และไมโคร Deye และข้อความ alarm บางรายการเป็นของแบบจำลอง ทิศลูกศร CT และการเปิดกันย้อนจริงต้องตรวจกับคู่มือ/ผู้ผลิตก่อนติดตั้ง ไม่มีการจำลองเครื่องปั่นไฟที่พอร์ต GEN
