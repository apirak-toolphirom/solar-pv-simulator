# เมนู 10 จำลองการไหลของไฟ

**ฉบับ 1.1 · ปรับปรุงล่าสุด 9 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/backup.js` `js/bkanim.js`

จำลองสมดุลพลังงานทุก 5 นาที ระหว่างแผง แบต โหลด และกริด ทั้งวันปกติ ไฟดับ และระบบ Off-grid ใช้พิกัด มุมเอียง ทิศ และวันที่เดียวกับเมนู 07

**ใครใช้ได้**: ค่าเริ่ม auto และผู้เยี่ยมชมเห็น (ใบงาน W4)

## ขั้นตอน
1. เลือกระบบ **On-grid / Hybrid / Off-grid**
2. ตรวจ **อินเวอร์เตอร์** และ **แบตเตอรี่** (ปรับจำนวนแบตที่เมนู 02)
3. **แหล่งไฟจากแผง**: แผงสมมติ (ไม่ตรวจการต่อสาย กำหนด **จำนวนแผงสมมติ**) หรือตามที่ต่อสายไว้ในเมนู 03
4. **โหลดที่ต้องจ่ายตอนจ่ายไฟเอง**: เฉพาะโหลด Backup หรือโหลดทั้งหมด (โหลดมาจากเมนู 09)
5. **แบตเริ่มต้นที่เวลา 00:00 (% SOC)**
6. **ไฟดับ**: ไม่มีไฟดับ หรือ มีไฟดับ → ตั้ง **เริ่มดับ** และ **นาน** (1–24 ชม.)
7. **การขายไฟคืนกริด**: ขายได้ / Zero export / จำกัดกำลังขาย (W) · ติ๊ก **มิเตอร์ Huawei (Smart Power Sensor)** ถ้าใช้ Huawei

## ภาพเคลื่อนไหว
**▶ เล่นทั้งวัน** (ช้า / ปกติ / เร็ว) · กระโดดไป 08:00 · 12:00 · 19:00 · **ช่วงไฟดับ** · **☁ เพิ่มเมฆ** (บาง 40% / ปานกลาง 75% / หนา 95% · ก้อนเล็ก กลาง ใหญ่) เพื่อดูผลต่อการไหลของไฟ

## อ่านผล
- **กำลังจากแผง โหลด และไฟจากกริด** กราฟทั้งวัน
- **สถานะประจุแบต (SOC)**
- ภาพการไหลบอกทิศไฟ: แผง → โหลด → แบต → กริด

ลำดับที่จำลอง: แผงจ่ายโหลดก่อน ส่วนเกินชาร์จแบต แล้วจึงขายคืน · ไม่รวมการชาร์จจากกริด derating ตามอุณหภูมิแบต และการสตาร์ทมอเตอร์

## เชื่อมกับเมนูอื่น
ติ๊กใช้ผลจากเมนู 04 แล้ว: ต่อ BACKUP ผิด = ไฟดับไม่มีไฟ · ตั้ง Export limit = ขายเกินไม่ได้ · ตั้ง SOC สำรอง = แบตไม่จ่ายต่ำกว่าค่านั้นตอนมีกริด · ค่าแผง ไฟดับ และ SOC ใช้ร่วมกับเมนู 11

## ใบงาน W4
ไฟดับอย่างน้อย 6 ชม. · Backup จ่ายโหลดได้พอ · โหลด ≥ 5 รายการ

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| ไฟดับแล้วโหลดดับหมด | ระบบ On-grid ไม่มีแบต หรือโหลดไม่ได้ต่อช่อง Backup (เมนู 09) |
| แบตหมดก่อนไฟมา | ลดโหลด Backup เพิ่มแบตในเมนู 02 หรือเริ่ม SOC สูงขึ้น |
