# ใบงาน: วัด Fill Factor (FF) ของแผงโซลาร์เซลล์ เมื่อไม่มีเครื่อง I-V Curve Tracer

**ฉบับ 1.0 · ปรับปรุงล่าสุด 21 พ.ย. 2569** · [กลับสารบัญ](README.md) · เกี่ยวกับ [เมนู 00 หัวข้อ 3, 4, 13](manual-00-basics.md)

ใช้ในหลักสูตรโซลาร์เซลล์สำหรับครัวเรือน ภาคปฏิบัติ กลุ่มละ 3–4 คน ใช้เวลาประมาณ 60 นาที ค่าในตัวอย่างเป็นข้อมูลสมมติเพื่อการเรียนรู้ ให้ใช้ค่าจากป้ายแผงและการวัดจริงของกลุ่มตัวเองในการส่งงาน

## 1. หลักการ

Fill Factor บอกว่าเส้นโค้ง I-V ของแผง "เต็มสี่เหลี่ยม" Voc × Isc มากแค่ไหน แผงสภาพดีจะมี FF สูง แผงที่ความต้านทานอนุกรมสูง มีเซลล์แตก มีไดโอดผิดปกติ หรือเสื่อม จะมี FF ต่ำลง

```
FF = Pmax / (Voc × Isc) = (Vmp × Imp) / (Voc × Isc)
```

| สัญลักษณ์ | ความหมาย | วัดอย่างไร |
|---|---|---|
| Voc | แรงดันวงจรเปิด | วัดคร่อมขั้ว + − ขณะไม่ต่อโหลด |
| Isc | กระแสลัดวงจร | ลัดขั้วผ่านสวิตช์ DC แล้ววัดด้วยแคลมป์ DC |
| Pmax | กำลังสูงสุด | ค่า V × I สูงสุดจากการไล่โหลด |
| Vmp, Imp | แรงดันและกระแสที่จุด Pmax | อ่านจากจุดที่ได้ Pmax |

ค่า FF ไม่ไวต่อความเข้มแสงและอุณหภูมิเท่า Pmax จึงเทียบกับค่าตามป้ายแผงได้แม้ไม่ใช่เงื่อนไข STC ถ้าแดดนิ่งและแรงพอ

## 2. ความปลอดภัย (ต้องอ่านก่อนทำ)

- แรงดัน DC ของแผงและสตริงเป็นอันตราย ใช้ถุงมือและเครื่องมือวัดที่ได้มาตรฐาน DC ทำเป็นทีม อย่าทำคนเดียว
- วัด Isc ด้วยแคลมป์มิเตอร์ DC ผ่านสายลัดที่ต่อ **ผ่านสวิตช์ตัดตอน DC** (สวิตช์ OFF) แล้วคล้องแคลมป์ก่อนปิดสวิตช์ ห้ามเสียบสายมิเตอร์ช่อง A ตรงขั้วแผง (เกินพิกัด ฟิวส์ขาด และเกิดอาร์ก)
- ห้ามถอดหัว MC4 หรือถอดสายลัดขณะมีกระแสไหล ต้องเปิดสวิตช์ DC (OFF) ก่อนทุกครั้ง
- รีโอสตัทหรือตัวต้านทานโหลดต้องรับกำลังได้มากกว่า Pmax ของแผง (แผง 550 W ต้องใช้โหลดรับได้อย่างน้อย 600 W) และจะร้อนมาก ห้ามจับ
- วัดทีละแผง ไม่วัดทั้งสตริงในครั้งแรก

## 5. วิธี A: ไล่โหลด 15 จุด (แม่นที่สุด)

1. ต่อวงจร: แผง → สวิตช์ DC (OFF) → รีโอสตัท มัลติมิเตอร์วัด V ขนานแผง แคลมป์ DC คล้องสายเส้นเดียวเพื่ออ่าน I
2. **Voc**: เปิดสวิตช์ DC (OFF) ไม่ต่อโหลด วัดแรงดันคร่อมแผง จดลงช่อง Voc
3. **Isc**: ลัดขั้วผ่านสวิตช์ DC (OFF) คล้องแคลมป์ ปิดสวิตช์ (ON) อ่านกระแส จดแล้วเปิดสวิตช์ (OFF) ก่อนถอดสายลัด
4. ต่อรีโอสตัทแทนสายลัด ปิดสวิตช์ (ON) ปรับโหลดจากเกือบ 0 Ω ไปมาก ๆ ทีละขั้น รอให้ค่านิ่ง 2–3 วินาที จด V และ I ให้ได้ **15 จุด** โดยใช้เวลารวมไม่เกิน 2 นาที
5. เก็บจุดให้ถี่ช่วง **โค้งเข่า** (ประมาณ 75–85% ของ Voc) เพราะ Pmax อยู่แถวนั้น
6. เสร็จแล้วเปิดสวิตช์ (OFF) วัดความเข้มแสงและอุณหภูมิหลังแผงอีกครั้ง

## 6. วิธี B: อ่าน Vmp/Imp จากอินเวอร์เตอร์หรือ MPPT (ประเมินคร่าว ๆ)

ใช้เมื่อไม่มีรีโอสตัท ทำกับสตริงหรือแผงที่ต่ออยู่กับอินเวอร์เตอร์/ชาร์จคอนโทรลเลอร์ MPPT

1. วัด Voc ของสตริงก่อนปิดสวิตช์ DC และวัด Isc ด้วยวิธีสายลัดผ่านสวิตช์ DC ตามข้อ 5
2. เปิดอินเวอร์เตอร์ให้ทำงานเต็มที่ในแดดนิ่ง อ่านแรงดันและกระแส DC ของอินพุต MPPT จากหน้าจอ หรือจากมิเตอร์ที่คร่อมและคล้องสาย DC ค่าเหล่านี้คือ Vmp, Imp โดยประมาณ
3. อ่านซ้ำ 3 ครั้งห่างกัน 30 วินาที หาค่าเฉลี่ย
4. FF = (Vmp × Imp) / (Voc × Isc) โดย Voc และ Isc เป็นของสตริงเดียวกัน

| ครั้งที่ | Vmp (V) | Imp (A) | P (W) |
|:-:|:-:|:-:|:-:|
| 1 | | | |
| 2 | | | |
| 3 | | | |
| เฉลี่ย | | | |

ข้อจำกัด: MPPT แกว่งรอบจุดกำลังสูงสุด และอาจลดกำลังเมื่อเกินพิกัดอินเวอร์เตอร์ ค่าที่ได้จึงต่ำกว่าหรือคลาดเคลื่อนจากวิธี A เล็กน้อย

## 7. เกณฑ์ประเมินผลโดยประมาณ

| FF ที่วัดได้ | การแปลผล |
|---|---|
| 0.78–0.84 | ปกติสำหรับแผง Mono / TOPCon สภาพดี |
| 0.72–0.78 | ปกติสำหรับแผง Poly หรือ Mono รุ่นเก่า |
| ต่ำกว่าค่าป้ายแผง 5–10% | เฝ้าระวัง ตรวจจุดต่อ ความสะอาด เงาบางส่วน |
| ต่ำกว่าค่าป้ายแผงเกิน 10% หรือต่ำกว่า 0.70 | ผิดปกติ สงสัยความต้านทานอนุกรมสูง เซลล์แตก ไดโอดบายพาสผิดปกติ เสื่อม หรือเงาบัง |

เกณฑ์ข้างต้นเป็นค่าประมาณเพื่อการเรียนรู้ ให้ตรวจกับดาต้าชีตของผู้ผลิตแผงที่ใช้จริง

## 8. แหล่งความคลาดเคลื่อนที่พบบ่อย

| อาการ | สาเหตุที่เป็นไปได้ |
|---|---|
| FF สูงเกิน 0.85 | ความเข้มแสงเปลี่ยนระหว่างไล่โหลด หรือวัด Isc/Voc ผิดจังหวะ |
| จุด P ไม่เป็นเส้นโค้งเรียบ (กระโดด) | แสงไม่นิ่ง หรือหน้าสัมผัสหลวม ให้ทำใหม่ |
| Isc ที่วัดได้ต่ำกว่าป้ายมาก | ความเข้มแสงต่ำกว่า 1000 W/m² เป็นเรื่องปกติ ให้เทียบ Isc/ความเข้มแสง ไม่ใช่เทียบตรง ๆ |
| Voc ต่ำกว่าป้ายเล็กน้อย | แผงร้อนกว่า 25 °C แรงดันลดประมาณ 0.25–0.3% ต่อองศา ดูค่าจากดาต้าชีต |
| มิเตอร์ช่อง A ฟิวส์ขาด | เสียบวัดกระแสตรงขั้วแผง ให้ใช้แคลมป์ DC คล้องสายลัดแทน |

## 9. คำถามท้ายใบงาน

1. เหตุใดต้องเก็บจุดให้ถี่บริเวณโค้งเข่าของเส้นโค้ง I-V
2. ถ้าความเข้มแสงลดลงครึ่งหนึ่ง Isc, Voc และ FF จะเปลี่ยนอย่างไร ค่าใดเปลี่ยนมากที่สุด
3. FF ของแผงกลุ่มคุณต่างจากค่าตามป้ายกี่เปอร์เซ็นต์ และคิดว่าเกิดจากสาเหตุใด
4. ทำไมการวัดด้วยวิธี B จึงให้ผลคร่าว ๆ กว่าวิธี A
5. เพราะเหตุใดห้ามถอดสายลัดขณะสวิตช์ DC ปิดวงจรอยู่

## 10. สิ่งที่ต้องส่ง

- ตารางบันทึก 15 จุดและตารางคำนวณที่กรอกครบ
- กราฟ I-V และ P-V ที่พล็อตจากข้อมูล (วาดมือหรือใช้โปรแกรม) ทำเครื่องหมายจุด Pmax
- คำตอบข้อ 9
- รูปถ่ายการต่อวงจรหน้างาน 1 รูป
