# เมนู 15 Huawei FusionSolar

**ฉบับ 1.0 · ปรับปรุงล่าสุด 5 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/fusion*.js` `js/hwlog.js`

หน้าจอจำลองสไตล์ FusionSolar / SUN2000 สำหรับฝึกอ่านค่าและวิเคราะห์ alarm โดยไม่ต้องมีเครื่องจริง และหน้าอ่าน log ที่ส่งออกจากระบบจริง ข้อมูลจำลองมาจากการต่อสายและตั้งค่าในเมนูก่อนหน้า ไม่ได้เชื่อมต่อ Huawei จริง

**ใครใช้ได้**: ค่าเริ่ม auto · ส่วน **อ่าน log** ใช้ได้เฉพาะผู้เรียนที่ลงชื่อแล้วและผู้สอน ผู้เยี่ยมชมไม่เห็นเสมอ

## หน้าย่อย
| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวมโรงไฟฟ้า | กำลังผลิตรายวัน พลังงานที่ผลิต (วัน / เดือน / ปี) เลื่อนเวลาและ **เล่น** ตั้งค่าไฟ ฿/kWh และพลังงานสะสมเดิม |
| Details | ข้อมูลอินเวอร์เตอร์ Real-Time Device Data · Basic Information · String Details และปุ่มควบคุม |
| Alarms | รายการ alarm ที่เกิดจากฟอลต์ |
| Historical Information | ข้อมูลย้อนหลัง |
| Configuration | ตั้งค่าตามจอ SUN2000 ค่าที่มี ★ มีผลต่อการจำลอง แก้แล้วกด **Save** กลับไปดูผล · **คืนค่าเริ่มต้น** · Export · Refresh |
| คู่มือ (แปลไทย) | คำอธิบายหน้าจอและค่าต่างๆ |
| อ่าน log (นำเข้าไฟล์) | วิเคราะห์ไฟล์ log จริง ดูด้านล่าง |

ถ้าเมนู 03 ยังไม่มีการต่อสาย DC ที่ผ่าน ระบบใช้ชุดแผงสมมติให้พอดีกับอินเวอร์เตอร์ที่เลือก

## สำหรับผู้สอน: สร้างฟอลต์
ส่วน **ครูสร้างฟอลต์** ตั้งช่วงที่เกิดฟอลต์ (ตั้งแต่ – ถึง) และรูปแบบ **ค่อยๆ เพิ่ม** หรือ **เกิดทันที** ให้ผู้เรียนหาสาเหตุจากกราฟและ alarm

## อ่าน log จากระบบจริง
1. ส่งออกไฟล์จาก Huawei (ชื่อเมนูอาจต่างตามเวอร์ชันแอป)
   - รายช่วงเวลา 5 นาที: FusionSolar → เลือกโรงไฟฟ้า → Devices → อินเวอร์เตอร์ → Historical data → เลือกค่า → Export
   - รายงานรายวัน/รายเดือน: Report → รายงานโรงไฟฟ้าหรืออินเวอร์เตอร์ → ส่งออก
   - แจ้งเตือน: Alarms → เลือกช่วงเวลา (รวมที่หายแล้ว) → ส่งออก
2. **เลือกไฟล์ log** (CSV / XLSX / XLS หลายไฟล์พร้อมกันได้) และกรอก **ขนาดติดตั้ง (kWp)** · ฝึกก่อนด้วย **ใช้ข้อมูลตัวอย่าง** หรือ **ดาวน์โหลดไฟล์ตัวอย่าง CSV**
3. ถ้าหัวคอลัมน์จับคู่ผิด แก้ใน **ตรวจคอลัมน์ที่ระบบจับคู่** (ชนิดข้อมูล: อัตโนมัติ / รายช่วงเวลา / รายงานรายวัน-เดือน / แจ้งเตือน)
4. เลือก **วันที่** แล้วดู
   - **ข้อสังเกตอัตโนมัติ**: clipping, ข้อมูลขาด, สตริงไม่เท่ากัน/เงาตอนเช้า, แรงดันกริดนอก 207–253 V, กริดหาย, อุณหภูมิสูง, SOC ต่ำ
   - กราฟ: กำลังไฟฟ้าตลอดวัน · แรงดันและกระแสสตริง · แรงดันกริด · SOC แบตและอุณหภูมิ · พลังงานรายวัน/รายเดือน (ช่วงที่มี alarm แสดงเป็นแถบสี)
   - **รายการแจ้งเตือน** กรองระดับ (ร้ายแรง / เตือน / อื่นๆ) พร้อมระยะเวลาและแนวทางตรวจเบื้องต้นของรหัสที่พบบ่อย
5. **ส่งออก CSV ของวันนี้ (จัดเรียงแล้ว)** · **ล้างข้อมูลทั้งหมด**

ไฟล์อ่านในเบราว์เซอร์เท่านั้น ไม่ส่งไปที่ใด ไม่บันทึกไปกับโปรเจ็ค ล้างเมื่อออกจากระบบหรือโหลดหน้าใหม่ · เกณฑ์ข้อสังเกตเป็นค่าประมาณ ไม่ใช่ผลวินิจฉัย งานที่ต้องเปิดฝาหรือปลดสายให้ผู้ได้รับอนุญาตทำ
