## ส่วนที่ 1 สำหรับผู้ใช้งาน

### เปิดเครื่องคำนวณ
มี 2 ทาง
1. **ในโปรแกรมจำลอง**: เมนู **17 คำนวณความคุ้มค่า** (กลุ่ม "ออกแบบและจำลอง") เมนูนี้จะเห็นก็ต่อเมื่อผู้สอนเปิดให้แล้ว
2. **หน้าเดี่ยว**: เปิด `calc.html` ของเว็บไซต์โดยตรง ไม่ต้องลงชื่อ เหมาะส่งลิงก์ให้ประชาชนทั่วไป

### เช็กสิทธิก่อนเริ่ม
- หน้าเดี่ยว: หน้าต่าง "เช็กสิทธิง่ายๆ ก่อนรับเงินสนับสนุน" ขึ้นทันทีที่เปิด
- ในโปรแกรมจำลอง: กดปุ่ม **ⓘ เงื่อนไขรับเงินสนับสนุนและเอกสารที่ต้องเตรียม** ด้านบน

หน้าต่างนี้บอกเงื่อนไข (ขนาดระบบที่ได้สิทธิ์ ชื่อผู้สมัครต้องตรงเจ้าของมิเตอร์ การผูก PromptPay การรับประกัน) และรายการเอกสาร กด **เข้าใจแล้ว ปิดหน้าต่าง** เพื่อเริ่มคำนวณ ในหน้าเดี่ยวเปิดซ้ำได้ที่ปุ่ม ⓘ มุมซ้ายล่าง

### ขั้นที่ 1 ค่าไฟต่อเดือน
1. พิมพ์ค่าไฟในช่อง ฿ หรือเลื่อนแถบ (0–20,000 บาท) หรือกดปุ่มเลือกเร็ว ฿0 / 2,500 / 4,000 / 6,000 / 10,000
2. ดูจำนวนหน่วยโดยประมาณที่มุมขวาบน
3. เลือกช่วงที่ใช้ไฟมาก
   - **เน้นกลางคืน** (กลางวัน 30%) บ้านที่ออกไปทำงานกลางวัน เปิดแอร์ตอนนอน
   - **พอๆ กัน** (50%)
   - **เน้นกลางวัน** (70%) มีคนอยู่บ้าน ร้านค้า หรือ work from home
4. ปรับละเอียดได้ที่ช่อง % กลางวัน / กลางคืน หรือแถบเลื่อนด้านล่าง (สองช่องรวมกันเป็น 100% เสมอ)

> ยิ่งใช้ไฟกลางวันมาก ยิ่งคุ้ม เพราะไฟที่ผลิตได้ถูกใช้เองแทนการซื้อจากการไฟฟ้า ส่วนที่เหลือขายคืนได้ราคาต่ำกว่า

### ขั้นที่ 2 เลือกขนาดระบบ
1. กดแพ็กเกจ 5 kW / 6 kW / 10 kW ตามช่วงค่าไฟที่เขียนไว้ใต้แต่ละแพ็กเกจ
2. หรือปรับเองในกล่อง **ปรับเลือก แผงโซลาร์ · Inverter · แบตเตอรี่**
   - ขนาดแผง (kWp) 3–10
   - Inverter (kW) 3–10 เมื่อเพิ่มขนาดแผง โปรแกรมเลื่อน Inverter ให้พอดีอัตโนมัติ
   - แบตเตอรี่ (kWh) ไม่ใช้ / 5 / 10 / 15 / 20
3. ข้อความเตือนสีส้มจะขึ้นเมื่อ
   - ขนาดแผงไม่อยู่ในช่วงที่ได้เงินสนับสนุน (ค่าเริ่ม 5–10 kWp)
   - Inverter เล็กกว่าแผงเกิน 30% (ไฟส่วนเกินถูกตัดทิ้ง)
4. ราคา
   - ติ๊ก **คำนวณราคาตามสเปคอัตโนมัติ** ไว้ ราคาจะเปลี่ยนตามสเปค
   - เอาติ๊กออกเพื่อพิมพ์ราคาจากใบเสนอราคาจริง
   - ช่อง **ค่าบริการ / งานติดตั้งเพิ่มเติม** ใส่ค่าสำรวจ เดินสายเพิ่ม งานเสริม
5. กล่องสีฟ้าด้านล่างแสดงราคาหลังหักเงินสนับสนุนจากรัฐ

### ขั้นที่ 3 กู้หรือจ่ายสด
- **กู้สินเชื่อธนาคาร**: แสดงยอดหลังหักรัฐ วงเงินกู้ (ไม่เกินวงเงินสูงสุด) และเงินดาวน์ส่วนที่เกิน
- **ไม่กู้ (จ่ายเงินสดเอง)**: แสดงยอดจ่ายเต็ม เงินที่ได้คืนเข้า PromptPay และต้นทุนสุทธิ

### ปรับสมมติฐาน (ไม่บังคับ)
ท้ายหน้า กด **ปรับสมมติฐานการคำนวณ** เพื่อเปลี่ยนค่าไฟต่อหน่วย ราคาขายคืน หน่วยผลิตต่อ kWp เงินสนับสนุน ดอกเบี้ย ระยะผ่อน วงเงินกู้ และอัตราค่าไฟขึ้นต่อปี ค่าที่แก้ตรงนี้ใช้เฉพาะหน้าที่เปิดอยู่ ปิดหน้าแล้วกลับเป็นค่าเริ่ม

## ส่วนที่ 2 อ่านผลลัพธ์

| หัวข้อ | ความหมาย |
|---|---|
| ผลิตไฟฟรีได้เฉลี่ย | หน่วยที่ระบบผลิตได้ต่อเดือน |
| ส่วนที่ช่วยลดค่าไฟ | ไฟที่ผลิตแล้วใช้เองในบ้าน (กลางวัน + จากแบต) คิดเป็นเงิน |
| ส่วนที่ขายคืนการไฟฟ้า | ไฟส่วนเกินที่ขายคืน × ราคาขายคืน |
| รวมความคุ้มค่า | สองข้อบนรวมกัน ต่อเดือนและต่อปี |
| ค่าไฟหลังติดตั้งระบบ | ค่าไฟที่ยังต้องจ่าย หักรายได้ขายไฟแล้ว |
| ผ่อนต่อเดือนเท่าไหร่ | ค่างวดสินเชื่อ (เลือกจ่ายสด = ฿0) |
| ประหยัดสุทธิ (ช่วงผ่อน) | ความคุ้มค่าต่อเดือน − ค่างวด ติดลบ (สีแดง) แปลว่าช่วงผ่อนจ่ายมากกว่าเดิม |
| จุดคุ้มทุน | จำนวนปีที่ผลประหยัดสะสมเท่ากับต้นทุนหลังหักรัฐรวมดอกเบี้ย |
| ผลประหยัดสะสมสุทธิ 25 ปี | ผลประหยัดตลอดอายุระบบ หักต้นทุนและดอกเบี้ยแล้ว |
| เงินดาวน์/จ่ายวันเริ่มสัญญา | เงินที่ต้องมีวันทำสัญญา |

**กราฟเปรียบเทียบรายจ่ายต่อเดือน** มี 3 แท่ง
1. ก่อนติด: ค่าไฟเดิม (แดง)
2. ช่วงผ่อน: ค่าไฟที่เหลือ (ฟ้า) + ค่างวด (ม่วง) · จ่ายสดแสดงเป็น "หลังติด"
3. ผ่อนหมดแล้ว: เหลือค่าไฟอย่างเดียว

ถ้าแท่งที่ 2 เตี้ยกว่าแท่งที่ 1 แปลว่าผ่อนแล้วยังจ่ายน้อยกว่าเดิมตั้งแต่เดือนแรก

## ส่วนที่ 3 สำหรับผู้สอน

### เปิด/ปิดเมนูให้ผู้เรียน
1. ครั้งแรกเท่านั้น: คัดลอก `apps-script/Code.gs` ล่าสุดไปวางใน Apps Script → **Deploy → Manage deployments → Edit → New version** เพื่อให้แผ่น "เมนู" มีแถว `calc`
2. เปิดหน้า **สรุปงานส่ง** (`dashboard.html`) กรอกรหัสผู้สอน กด **โหลดข้อมูล**
3. ในตารางเมนู แถว **17 คำนวณความคุ้มค่า** เลือกสถานะ
   - **ปิด** (ค่าเริ่ม) ผู้เรียนไม่เห็นเมนู
   - **เปิด** ผู้เรียนใช้ได้
   - **ดูอย่างเดียว** ผู้เรียนเห็นแต่แก้ค่าไม่ได้
   - **auto** เปิดเมื่อมีใบงานที่ใช้เมนูนี้เปิดรับอยู่
4. ติ๊ก **ผู้เยี่ยมชมเห็น** ถ้าต้องการให้คนที่ไม่ได้ลงชื่อเห็นด้วย
5. มีผลทันที ผู้เรียนรีเฟรชหน้าเพื่อเห็นเมนู

โหมดผู้สอนเห็นเมนูนี้เสมอ ส่วนหน้าเดี่ยว `calc.html` ไม่มีการล็อกสิทธิ์ ใครมีลิงก์ก็เปิดได้

### แก้ค่าตั้งต้น
แก้ object `CONFIG` ด้านบนไฟล์ `calc.html`

| ค่า | ใช้ทำอะไร | ค่าเริ่ม |
|---|---|---|
| `provider.name` `provider.code` | ชื่อและรหัสผู้ให้บริการที่ขึ้นทะเบียน แสดงในหน้าต่างเช็กสิทธิและท้ายหน้า | ต้องแก้ก่อนใช้ |
| `provider.phone` `provider.line` | ช่องทางติดต่อท้ายหน้า | ว่าง |
| `tariff` | ค่าไฟเฉลี่ย บาท/หน่วย | 4.4 |
| `sellRate` | ราคาขายคืน บาท/หน่วย (0 = ไม่ขายคืน) | 2.2 |
| `yieldPerKwp` | หน่วยผลิตต่อ 1 kWp ต่อเดือน | 115 |
| `subsidy` `subsidyMinKwp` `subsidyMaxKwp` | เงินสนับสนุนและช่วงขนาดที่ได้สิทธิ์ | 50,000 · 5–10 |
| `loanRate` `loanYears` `loanCap` | ดอกเบี้ย flat ต่อปี ระยะผ่อน วงเงินกู้สูงสุด | 2.5% · 5 ปี · 90,000 |
| `tariffEscalation` `degradation` `years` | ค่าไฟขึ้นต่อปี แผงเสื่อมต่อปี อายุระบบ | 2% · 0.5% · 25 |
| `warrantyYears` | ปีรับประกันในหน้าต่างเช็กสิทธิ | 7 |
| `packages` | 3 แพ็กเกจในขั้นที่ 2 (ขนาด ป้าย ช่วงค่าไฟ ราคา) | 5/6/10 kW |
| `priceByKwp` | ราคาชุดตามขนาดแผงเมื่อคำนวณอัตโนมัติ | 3–10 kWp |
| `kwpOptions` `invOptions` `battOptions` | ตัวเลือกใน dropdown | |
| `invUpPerKw` `hybridExtra` `battPerKwh` | ส่วนเพิ่ม Inverter ใหญ่กว่าแผง, hybrid เมื่อมีแบต, ราคาแบตต่อ kWh | 6,000 · 15,000 · 7,000 |
| `documents` | รายการเอกสารที่ต้องเตรียม | 5 รายการ |

แก้แล้วรัน `python3 build.py` เพื่อสร้าง `index.html` และ `dist/pv-wiring-sim.html` ใหม่ จากนั้น commit และ push ขึ้น GitHub (Pages อัปเดตเองภายในไม่กี่นาที)

> ตรวจเงื่อนไขโครงการเงินสนับสนุน วงเงิน และดอกเบี้ยกับประกาศล่าสุดของหน่วยงานรัฐและธนาคารก่อนเปิดให้ผู้เรียนหรือประชาชนใช้

### ใช้ในการสอน
- ให้ผู้เรียนลองค่าไฟบ้านตัวเอง เทียบ "เน้นกลางวัน" กับ "เน้นกลางคืน" แล้วอธิบายว่าทำไมผลต่างกัน
- เทียบระบบ 5 kW ไม่มีแบต กับ 5 kW + แบต 10 kWh ดูว่าแบตทำให้คุ้มทุนเร็วขึ้นหรือช้าลง
- ตั้ง `sellRate` เป็น 0 ในสมมติฐาน เพื่อดูผลกรณีไม่ได้ขายไฟคืน
- ให้เปลี่ยนเป็นราคาจากใบเสนอราคาจริง แล้วตัดสินใจว่ากู้หรือจ่ายสดดีกว่า

## ส่วนที่ 4 วิธีคำนวณ

1. หน่วยต่อเดือน = ค่าไฟ ÷ `tariff`
2. โหลดกลางวัน = หน่วย × % กลางวัน · โหลดกลางคืน = ส่วนที่เหลือ
3. ไฟผลิต = kWp × `yieldPerKwp` (ถ้า Inverter × 1.3 < kWp ลดตามสัดส่วน)
4. ใช้เองกลางวัน = น้อยกว่าระหว่างไฟผลิตกับโหลดกลางวัน
5. ส่วนเกินชาร์จแบต: ใช้ได้ไม่เกิน แบต kWh × 0.9 × 30 วัน และไม่เกินโหลดกลางคืน (ประสิทธิภาพ 95%)
6. ส่วนเกินที่เหลือขายคืน × `sellRate`
7. ลดค่าไฟ = (ใช้เองกลางวัน + จากแบต) × `tariff` ไม่เกินค่าไฟเดิม
8. ต้นทุนสุทธิ = ราคาชุด + ค่าบริการ − เงินสนับสนุน (เฉพาะขนาดที่ได้สิทธิ์)
9. กู้: วงเงิน = น้อยกว่าระหว่างต้นทุนสุทธิกับ `loanCap` · ดาวน์ = ส่วนเกิน · ดอกเบี้ย = วงเงิน × `loanRate` × `loanYears` · ค่างวด = (วงเงิน + ดอกเบี้ย) ÷ (ปี × 12)
10. จุดคุ้มทุน = (ต้นทุนสุทธิ + ดอกเบี้ย) ÷ (ความคุ้มค่าต่อเดือน × 12)
11. ผลประหยัด 25 ปี = Σ ความคุ้มค่าต่อปี × (1 + `tariffEscalation`)^ปี × (1 − `degradation`)^ปี − ต้นทุนสุทธิ − ดอกเบี้ย

**ตัวอย่าง** ค่าไฟ ฿9,800 · กลางวัน 50% · 5 kW ไม่มีแบต · ราคา ฿140,000 · กู้
- ≈ 2,227 หน่วย/เดือน · ผลิต 575 หน่วย ใช้เองทั้งหมด → ลดค่าไฟ ≈ ฿2,530/เดือน
- หลังหักรัฐ ฿90,000 กู้เต็ม · ค่างวด ฿1,688 (ดอกเบี้ยรวม ฿11,250)
- ประหยัดสุทธิช่วงผ่อน ≈ +฿843/เดือน · คุ้มทุน ≈ 3.3 ปี

## ส่วนที่ 5 ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ผู้เรียนไม่เห็นเมนู 17 | ผู้สอนยังไม่เปิดที่ dashboard หรือยังไม่ได้ Deploy `Code.gs` เวอร์ชันใหม่ ให้ผู้เรียนรีเฟรชหน้าหลังเปิด |
| ไม่ได้หักเงินสนับสนุน | ขนาดแผงอยู่นอกช่วงที่ได้สิทธิ์ (ดูข้อความเตือนสีส้ม) |
| พิมพ์ราคาไม่ได้ | ติ๊ก "คำนวณราคาตามสเปคอัตโนมัติ" อยู่ ให้เอาติ๊กออก |
