# เมนู 18 Deye Commissioning

**ฉบับ 1.0 · ปรับปรุงล่าสุด 10 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/deye.js` `js/deyemi.js`

ฝึกต่อพอร์ต ตรวจวัดก่อนเปิดเครื่อง ลำดับ Power ON ตั้งค่าหน้าจอ และทดสอบการทำงานของ Deye Hybrid SUN-6K-SG04LP1-EU-SM2 (On-grid / Hybrid / Off-grid) และไมโครอินเวอร์เตอร์ Deye SUN-M200G4-EU-Q0

**ใครใช้ได้**: ค่าเริ่ม **ปิด** ผู้เรียนและผู้เยี่ยมชมไม่เห็นจนกว่าผู้สอนเลือก "เปิด" ที่ dashboard (ต้องวาง `Code.gs` ล่าสุดแล้ว Deploy → New version) ผู้สอนเห็นเสมอ

## เลือกระบบ (ใบสั่งงาน)
| ระบบ | ใบสั่งงาน |
|---|---|
| Hybrid On-grid | มีแบต ซื้อ-ขายไฟกับกริด (Selling First) |
| Hybrid ห้ามขาย | มีแบต ห้ามส่งไฟออกกริด (Zero Export To CT) |
| Hybrid Off-grid | ไม่มีกริด ใช้แผง + แบตอย่างเดียว |
| ไมโครอินเวอร์เตอร์ | SUN-M200G4-EU-Q0 ต่อแผงเข้าสาขา AC |

## ขั้นตอน (Hybrid)
1. **ใบสั่งงานและการต่อพอร์ต**: เลือกสิ่งที่ต่อเข้า PV1/PV2, BAT, GRID, LOAD, CT (ตำแหน่ง ทิศลูกศร), CAN ระบบตรวจข้อห้ามตามคู่มือ เช่น LOAD ห้ามต่อเข้ากริด
2. **ตรวจวัดและ Power ON/OFF**: เช็กลิสต์ก่อนติดตั้ง · มัลติมิเตอร์วัด PV, BAT, L–N, L–PE, N–PE, ความต่อเนื่อง PE ตรวจ CT และหัว CAN ด้วยตา
   - ลำดับเปิด: เบรกเกอร์แบต → DC switch → เบรกเกอร์ GRID → ปุ่ม ON/OFF · เบรกเกอร์ LOAD เปิดหลังตั้งค่าเสร็จ
3. **หน้าจอเครื่อง**: จอสัมผัส เมนู Basic Setup, Battery Setup, Work Mode, Grid Setup (ปลดล็อกด้วยรหัส 7777), Advanced, Device Info, Alarm · Work Mode: Selling First / Zero Export To Load / Zero Export To CT · TOU 6 ช่วงเวลา · Factory Reset รหัส 9999
4. **แดชบอร์ด**: แผง แบต กริด โหลด ตลอดวัน ตั้งไฟดับ เมฆ โหลดเพิ่ม ดูกราฟและสรุป kWh ผลเปลี่ยนตามการตั้งค่า
5. **โจทย์หาข้อผิดพลาด**: ระบบสุ่มความผิดพลาด ให้หาด้วยการวัดและ alarm เช่น CT กลับทิศ/หลุด, PV เกิน 500 V, PV2 กลับขั้ว, ฟิวส์แบตขาด, CAN pin ไม่ตรง, LOAD ต่อเข้ากริด, L/N สลับ, ไม่ต่อ PE

## ขั้นตอน (ไมโครอินเวอร์เตอร์)
1. เลือกจำนวนไมโครต่อสาขา (≤ 3 ตัวที่เบรกเกอร์ 40 A), ขนาดเบรกเกอร์ ปลายสาย สาย DC ยาวไม่เกิน 3 m, PE, RCD, SPD
2. ตรวจวัด: ขั้ว DC แรงดัน AC ต่อเนื่อง PE · เปิดเบรกเกอร์สาขา AC แล้วรอ 1 นาที ดู LED (น้ำเงินช้า/เร็ว, แดงกะพริบ แดง 2/3/4 = แรงดัน AC / กริด / GFDI)
3. ห้ามเสียบ DC ขณะ AC ยังไม่เสียบ · ลำดับปิด: เบรกเกอร์สาขา AC → ถอด AC → คลุมแผง → ถอด DC
4. เชื่อมต่อ Wi-Fi/แอป และดูแดชบอร์ดผลผลิตตลอดวัน
5. โจทย์หาข้อผิดพลาด: ขั้ว DC กลับ, ไม่ต่อ PE, L/N สลับ, เบรกเกอร์สาขาเล็กไป, ปลายสายผิด, GFDI

## อ่านผล
- ผ่านครบทุกข้อของระบบนั้น = นับ 1 ระบบ (`deye_done`)
- หาข้อผิดพลาดถูก = นับ 1 โจทย์ (`deye_diag`)

## เชื่อมกับเมนูอื่น
- เมนู 15 Solis Commissioning (ขั้นตอนคล้ายกัน เปรียบเทียบรุ่น) · เมนู 04 ต่อสาย AC · เมนู 06 สายไฟและเบรกเกอร์
- เมนู 19 ส่งงาน: ใบงาน **W15**

## ใบงาน
**W15 Commissioning Deye** (ค่าเริ่ม = ปิด): ผ่านครบอย่างน้อย 1 ระบบ และหาข้อผิดพลาดถูก 1 โจทย์ (`deye_done>=1;deye_diag>=1`)

## ปัญหาที่พบบ่อย
| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ไม่เห็นเมนู | ค่าเริ่มปิด ให้ผู้สอนเปิดที่ dashboard (วาง Code.gs ล่าสุด + Deploy New version) |
| แก้ค่าไม่ได้ในเมนู Grid Setup | ต้องปลดล็อกด้วยรหัส 7777 |
| ไมโครไม่ทำงานหลังต่อ | เปิดเบรกเกอร์สาขา AC แล้วรอ 1 นาที ตรวจ LED |
| ผ่านไม่ครบ | ดูรายการข้อที่ยังไม่ผ่านในเช็กลิสต์ แล้วแก้ตามข้อนั้น |

ค่าแผง (Voc 49.5 V, 650 W) โหลด และพฤติกรรมควบคุมเป็นแบบจำลอง ไม่ใช่เฟิร์มแวร์จริง ข้อความ alarm บางรายการ (เช่น F55 และ LOAD-GRID) เป็นข้อความของแบบจำลอง ลำดับปิดเครื่องเป็นคำแนะนำของแบบจำลอง ตรวจทิศลูกศร CT และรหัส grid code กับเครื่องและคู่มือฉบับล่าสุดทุกครั้ง
