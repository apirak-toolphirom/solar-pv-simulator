# เมนู 17 Huawei FusionSolar

**ฉบับ 1.5 · ปรับปรุงล่าสุด 10 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/fusion*.js` `js/hwlog.js`

หน้าจอจำลองสไตล์ FusionSolar / SUN2000 สำหรับฝึกอ่านค่าและวิเคราะห์ alarm โดยไม่ต้องมีเครื่องจริง และหน้าอ่าน log ที่ส่งออกจากระบบจริง ข้อมูลจำลองมาจากการต่อสายและตั้งค่าในเมนูก่อนหน้า ไม่ได้เชื่อมต่อ Huawei จริง

**ใครใช้ได้**: ค่าเริ่ม auto · ส่วน **อ่าน log** ใช้ได้เฉพาะผู้เรียนที่ลงชื่อแล้วและผู้สอน ผู้เยี่ยมชมไม่เห็นเสมอ

## หน้าย่อย
| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวมโรงไฟฟ้า | กำลังผลิตรายวัน พลังงานที่ผลิต (วัน / เดือน / ปี) เลื่อนเวลาและ **เล่น** ตั้งค่าไฟ ฿/kWh และพลังงานสะสมเดิม |
| Details | ข้อมูลอินเวอร์เตอร์ Real-Time Device Data · Basic Information · String Details และปุ่มควบคุม |
| Alarms | รายการ alarm ที่เกิดจากฟอลต์ |
| Historical Information | ข้อมูลย้อนหลัง |
| Configuration | ตั้งค่าตามจอ SUN2000 ค่าที่มี ★ มีผลต่อการจำลอง แก้แล้วกด **Save** กลับไปดูผล · **คืนค่าเริ่มต้น** · Export · Refresh |
| Commissioning (ฝึกเปิดเครื่อง) | ฝึกลำดับงาน commissioning อินเวอร์เตอร์ Huawei ทีละขั้น ดูหัวข้อด้านล่าง |
| คู่มือ (แปลไทย) | คำอธิบายหน้าจอและค่าต่างๆ |
| อ่าน log (นำเข้าไฟล์) | วิเคราะห์ไฟล์ log จริง ดูด้านล่าง |

ถ้าเมนู 03 ยังไม่มีการต่อสาย DC ที่ผ่าน ระบบใช้ชุดแผงสมมติให้พอดีกับอินเวอร์เตอร์ที่เลือก

## Commissioning (ฝึกเปิดเครื่อง)
จำลองลำดับงานของผู้ติดตั้งตั้งแต่วัดก่อนเปิดเครื่อง จนเครื่องขึ้น On-grid และตรวจผล ตามหัวข้อ 4 ของคู่มือในหน้า "คู่มือ (แปลไทย)" โจทย์คือบ้านในเขต PEA หรือ MEA (เลือกได้) ติดตั้งอินเวอร์เตอร์ที่เลือกในเมนู 02 ถ้าไม่ใช่ SUN2000 หน้านี้ใช้ SUN2000-10KTL-M0 ค่าสมมติ ติด Smart Dongle WLAN-FE แล้ว เจ้าของบ้านขอใช้ไฟเองโดยไม่ส่งออก ผู้เรียนเปลี่ยนขั้นด้วยปุ่ม 1–6 ด้านบน หรือ **ถัดไป / ย้อนกลับ**

| ขั้น | ทำอะไร | เกณฑ์ผ่าน |
|---|---|---|
| 1 ตรวจก่อนเปิด | ติ๊กรายการตรวจก่อนจ่ายไฟ 4 ข้อ แล้วกด **วัด** ครบ 5 จุด (Voc สตริง 1 และ 2, ฉนวน DC, AC L–N, N–PE) | ค่าที่วัดอยู่ในเกณฑ์ ถ้าผิด ให้กด **แก้ไขแล้ว** แล้ววัดใหม่ |
| 2 เชื่อมต่อแอป | เลือกวิธีเชื่อมต่อ (ใช้ได้เฉพาะ WLAN ผ่าน Smart Dongle) เลือกเครือข่ายที่ SN ตรงป้าย ล็อกอิน แล้วตั้งรหัสผ่านใหม่ | ล็อกอินสำเร็จและเปลี่ยนรหัส · ใส่รหัสผิด 5 ครั้งติดกันบัญชีล็อก 10 นาที (กด **ข้ามเวลา** เพื่อจำลอง) |
| 3 Quick settings | ตั้ง Grid code, Output mode (3 เฟส), เขตเวลา, Networking mode, เราเตอร์และรหัส WiFi, Active power control แล้วกด **บันทึกการตั้งค่า** | Grid code ตรงเขตการไฟฟ้า · Output mode เป็น four-wire · UTC+07:00 · WLAN-FE · เราเตอร์ 2.4 GHz · Zero export |
| 4 เปิดเครื่อง | กดเบรกเกอร์ AC แล้วสวิตช์ DC ดูไทม์ไลน์ของเครื่อง | เปิด AC ก่อน DC และเครื่องขึ้น On-grid |
| 5 ตรวจหลังเดิน | อ่านแรงดัน/กระแสสตริง และสถานะ LED ของ Smart Dongle | แรงดันสองสตริงต่างกันไม่เกิน 5% และ LED เขียวติดค้าง |
| 6 สรุปผล | ดูรายการผ่าน/ไม่ผ่านทั้งหมด **บันทึกรายงาน (.txt)** หรือ **เริ่มใหม่** | ผ่านทุกข้อ |

**ความผิดปกติที่ซ่อนอยู่**: ในขั้น 1 ผู้สอนเลือกได้ว่ารอบนี้มีสตริง 1 ขั้วกลับ, ต่ออนุกรมเกิน หรือฉนวน DC ต่ำ (หรือไม่มีเลย) ให้ผู้เรียนหาจากค่าที่วัด ถ้าเปิดเครื่องทั้งที่ยังไม่แก้ ขั้น 4 จะขึ้น alarm ตามชนิด (String Reverse Connection, High String Input Voltage, Low Insulation Resistance) พร้อมสาเหตุและวิธีแก้

**ข้อควรรู้**
- ค่า Quick settings ที่ผิดจะไม่ขึ้นเตือนบนเครื่องจริง หน้านี้จึงสรุปให้ตอนกดบันทึก เพื่อฝึกให้ผู้เรียนตรวจเอง
- LED ของ Dongle ในขั้น 5 ตรงกับตาราง 4-1 ในหน้า "คู่มือ (แปลไทย)" (เขียวติดค้าง = เชื่อมต่อสำเร็จ แดงกะพริบเร็ว = เชื่อมต่อเราเตอร์ไม่สำเร็จ)
- รหัสผ่านที่พิมพ์ไม่ถูกบันทึกไปกับโปรเจ็ค ส่วนความคืบหน้า (ขั้น ค่าที่วัด การตั้งค่า สวิตช์) ถูกบันทึกตามปกติ
- เกณฑ์ตัวเลข (ฉนวน ≥ 1 MΩ, AC 207–253 V ฯลฯ) เป็นเกณฑ์ของแบบฝึก งานจริงให้ตรวจกับคู่มือ Huawei, IEC 62446-1 และข้อกำหนดการไฟฟ้า

## สำหรับผู้สอน: สร้างฟอลต์
ส่วน **ครูสร้างฟอลต์** ตั้งช่วงที่เกิดฟอลต์ (ตั้งแต่ – ถึง) และรูปแบบ **ค่อยๆ เพิ่ม** หรือ **เกิดทันที** ให้ผู้เรียนหาสาเหตุจากกราฟและ alarm

## อ่าน log จากระบบจริง
1. ส่งออกไฟล์จาก Huawei (ชื่อเมนูอาจต่างตามเวอร์ชันแอป)
   - รายช่วงเวลา 5 นาที: FusionSolar → เลือกโรงไฟฟ้า → Devices → อินเวอร์เตอร์ → Historical data → เลือกค่า → Export
   - รายงานรายวัน/รายเดือน: Report → รายงานโรงไฟฟ้าหรืออินเวอร์เตอร์ → ส่งออก
   - แจ้งเตือน: Alarms → เลือกช่วงเวลา (รวมที่หายแล้ว) → ส่งออก
2. **เลือกไฟล์ log** (CSV / XLSX / XLS หลายไฟล์พร้อมกันได้) และกรอก **ขนาดติดตั้ง (kWp)** · ฝึกก่อนด้วย **ใช้ข้อมูลตัวอย่าง** หรือ **ดาวน์โหลดไฟล์ตัวอย่าง CSV**
3. ถ้าหัวคอลัมน์จับคู่ผิด แก้ใน **ตรวจคอลัมน์ที่ระบบจับคู่** (ชนิดข้อมูล: อัตโนมัติ / รายช่วงเวลา / รายงานรายวัน-เดือน / แจ้งเตือน)
4. เลือก **วันที่** แล้วดู
   - **ข้อสังเกตอัตโนมัติ**: clipping, ข้อมูลขาด, สตริงไม่เท่ากัน/เงาตอนเช้า, แรงดันกริดนอก 207–253 V, กริดหาย, อุณหภูมิสูง, SOC ต่ำ
   - กราฟ: กำลังไฟฟ้าตลอดวัน · แรงดันและกระแสสตริง · แรงดันกริด · SOC แบตและอุณหภูมิ · พลังงานรายวัน/รายเดือน (ช่วงที่มี alarm แสดงเป็นแถบสี)
   - **รายการแจ้งเตือน** กรองระดับ (ร้ายแรง / เตือน / อื่นๆ) พร้อมระยะเวลาและแนวทางตรวจเบื้องต้นของรหัสที่พบบ่อย
5. **ส่งออก CSV ของวันนี้ (จัดเรียงแล้ว)** · **ล้างข้อมูลทั้งหมด**

ไฟล์อ่านในเบราว์เซอร์เท่านั้น ไม่ส่งไปที่ใด ไม่บันทึกไปกับโปรเจ็ค ล้างเมื่อออกจากระบบหรือโหลดหน้าใหม่ · เกณฑ์ข้อสังเกตเป็นค่าประมาณ ไม่ใช่ผลวินิจฉัย งานที่ต้องเปิดฝาหรือปลดสายให้ผู้ได้รับอนุญาตทำ

## ใบงาน
**W13 อ่าน log Huawei FusionSolar** (ค่าเริ่ม = ปิด ผู้สอนเปิดที่ dashboard): นำเข้าไฟล์ log อย่างน้อย 1 ไฟล์ · คำถาม 2 ข้อ (พลังงานที่ผลิตได้และแจ้งเตือนที่พบ) · ส่งที่เมนู 18

**W14 Commissioning Huawei SUN2000** (ค่าเริ่ม = ปิด ผู้สอนเปิดที่ dashboard): ทำหน้า "Commissioning (ฝึกเปิดเครื่อง)" ให้ผ่านทุกข้อ เกณฑ์ตรวจอัตโนมัติ 5 ข้อ ได้แก่ ตรวจและวัดก่อนเปิดเครื่อง · เชื่อมต่อแอปและล็อกอิน · Quick settings · เปิดเครื่องถึง On-grid · ตรวจหลังเดินเครื่อง (เช็กลิสต์แสดงจำนวนข้อที่ผ่านของแต่ละกลุ่ม) · คำถาม 3 ข้อ (ความผิดปกติที่พบจากค่าที่วัด · เหตุผลที่ต้องเปิด AC ก่อน DC และเลือก Grid code ให้ตรงเขต · ความหมายของ LED แดงกะพริบเร็ว) · ส่งที่เมนู 18 ผลอยู่ในเครื่องที่ส่งงาน ถ้าผู้เรียนกด **เริ่มใหม่** เกณฑ์จะกลับเป็นยังไม่ผ่าน

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| ไม่เห็นหน้าอ่าน log | ต้องลงชื่อเป็นผู้เรียนหรือผู้สอน |
| Commissioning: ขั้น 3 ขึ้นว่ายังไม่ได้ล็อกอิน | กลับไปขั้น 2 ให้ล็อกอินและตั้งรหัสผ่านใหม่ให้เสร็จ |
| Commissioning: ขั้น 5 ขึ้นว่าเครื่องยังไม่ On-grid | กลับไปขั้น 4 เปิด AC แล้ว DC และแก้ความผิดปกติจากขั้น 1 ก่อน |
| Commissioning: LED Dongle เป็นแดง | ดูสาเหตุใต้ LED แล้วแก้ที่ขั้น 3 (Networking mode, เราเตอร์ 2.4 GHz, รหัส WiFi) |
| อ่านไฟล์ Excel ไม่ได้ในไฟล์หน้าเดียว | `dist/` โหลดไลบรารีจาก CDN ต้องมีอินเทอร์เน็ต |
| กราฟว่าง | จับคู่คอลัมน์หรือชนิดข้อมูลผิด แก้ใน "ตรวจคอลัมน์" |
