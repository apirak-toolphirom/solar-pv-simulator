# เมนู 17 Huawei FusionSolar

**ฉบับ 2.3 · ปรับปรุงล่าสุด 22 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/fusion*.js` `js/hwlog.js` `js/hwplot.js`

หน้าจอจำลองสไตล์ FusionSolar / SUN2000 สำหรับฝึกอ่านค่าและวิเคราะห์ alarm โดยไม่ต้องมีเครื่องจริง และหน้าอ่าน log ที่ส่งออกจากระบบจริง ข้อมูลจำลองมาจากการต่อสายและตั้งค่าในเมนูก่อนหน้า ไม่ได้เชื่อมต่อ Huawei จริง

**ใครใช้ได้**: ค่าเริ่ม auto · ส่วน **อ่าน log** ใช้ได้เฉพาะผู้เรียนที่ลงชื่อแล้วและผู้สอน ผู้เยี่ยมชมไม่เห็นเสมอ

## หน้าย่อย
| หน้า | ใช้ทำอะไร |
|---|---|
| ภาพรวมโรงไฟฟ้า | กำลังผลิตรายวัน พลังงานที่ผลิต (วัน / เดือน / ปี) เลื่อนเวลาและ **เล่น** ตั้งค่าไฟ ฿/kWh และพลังงานสะสมเดิม |
| Details | ข้อมูลอินเวอร์เตอร์ Real-Time Device Data · Basic Information · String Details และปุ่มควบคุม |
| Alarms | รายการ alarm ที่เกิดจากฟอลต์ |
| Historical Information | ข้อมูลย้อนหลัง |
| Configuration | ตั้งค่าตามจอ SUN2000 ค่าที่มี ★ มีผลต่อการจำลอง แก้แล้วกด **Save** กลับไปดูผล · **คืนค่าเริ่มต้น** · Export · Refresh |
| Commissioning (ฝึกเปิดเครื่อง) | ฝึกลำดับงาน commissioning อินเวอร์เตอร์ Huawei ทีละขั้น ดูหัวข้อด้านล่าง |
| คู่มือ (แปลไทย) | คำอธิบายหน้าจอและค่าต่างๆ |
| อ่าน log (นำเข้าไฟล์) | วิเคราะห์ไฟล์ log จริง ดูด้านล่าง |

ถ้าเมนู 03 ยังไม่มีการต่อสาย DC ที่ผ่าน ระบบใช้ชุดแผงสมมติให้พอดีกับอินเวอร์เตอร์ที่เลือก

## Commissioning (ฝึกเปิดเครื่อง)
จำลองลำดับงานของผู้ติดตั้งตั้งแต่วัดก่อนเปิดเครื่อง จนเครื่องขึ้น On-grid และตรวจผล ตามหัวข้อ 4 ของคู่มือในหน้า "คู่มือ (แปลไทย)" โจทย์คือบ้านในเขต PEA หรือ MEA (เลือกได้) ติดตั้งอินเวอร์เตอร์ที่เลือกในเมนู 02 ถ้าไม่ใช่ SUN2000 หน้านี้ใช้ SUN2000-10KTL-M0 ค่าสมมติ ติด Smart Dongle WLAN-FE แล้ว เจ้าของบ้านขอใช้ไฟเองโดยไม่ส่งออก ผู้เรียนเปลี่ยนขั้นด้วยปุ่ม 1–6 ด้านบน หรือ **ถัดไป / ย้อนกลับ**

| ขั้น | ทำอะไร | เกณฑ์ผ่าน |
|---|---|---|
| 1 ตรวจก่อนเปิด | ติ๊กรายการตรวจก่อนจ่ายไฟ 4 ข้อ แล้วกด **วัด** ครบ 5 จุด (Voc สตริง 1 และ 2, ฉนวน DC, AC L–N, N–PE) | ค่าที่วัดอยู่ในเกณฑ์ ถ้าผิด ให้กด **แก้ไขแล้ว** แล้ววัดใหม่ |
| 2 เชื่อมต่อแอป | เลือกวิธีเชื่อมต่อ (ใช้ได้เฉพาะ WLAN ผ่าน Smart Dongle) เลือกเครือข่ายที่ SN ตรงป้าย ล็อกอิน แล้วตั้งรหัสผ่านใหม่ | ล็อกอินสำเร็จและเปลี่ยนรหัส · ใส่รหัสผิด 5 ครั้งติดกันบัญชีล็อก 10 นาที (กด **ข้ามเวลา** เพื่อจำลอง) |
| 3 Quick settings | ตั้ง Grid code, Output mode (3 เฟส), เขตเวลา, Networking mode, เราเตอร์และรหัส WiFi, Active power control แล้วกด **บันทึกการตั้งค่า** | Grid code ตรงเขตการไฟฟ้า · Output mode เป็น four-wire · UTC+07:00 · WLAN-FE · เราเตอร์ 2.4 GHz · Zero export |
| 4 เปิดเครื่อง | กดเบรกเกอร์ AC แล้วสวิตช์ DC ดูไทม์ไลน์ของเครื่อง | เปิด AC ก่อน DC และเครื่องขึ้น On-grid |
| 5 ตรวจหลังเดิน | อ่านแรงดัน/กระแสสตริง และสถานะ LED ของ Smart Dongle แล้วดู **หน้า Monitor ของแอป FusionSolar (Power flow)** และส่วน **ฝึกอ่านจากจอจริง** | แรงดันสองสตริงต่างกันไม่เกิน 5% และ LED เขียวติดค้าง |
| 6 สรุปผล | ดูรายการผ่าน/ไม่ผ่านทั้งหมด **บันทึกรายงาน (.txt)** หรือ **เริ่มใหม่** | ผ่านทุกข้อ |

**หน้า Monitor (Power flow) ในขั้น 5**: แผนภาพแบบหน้าแรกของแอป FusionSolar แสดงแผง PV → อินเวอร์เตอร์ → กริด / โหลดบ้าน / แบตเตอรี่ จุดเขียวที่เคลื่อนไหวคือทิศทางที่พลังงานไหล เส้นเทาคือไม่มีการไหล (ถ้าตั้งให้ลดการเคลื่อนไหวในอุปกรณ์ จุดจะหยุดนิ่ง) ข้างอินเวอร์เตอร์แสดงกำลัง AC พร้อมแรงดัน/กระแสแต่ละเฟส ใต้แผงแสดง PV1/PV2 สมมติโหลดบ้าน 3.5 kW เครื่อง SUN2000-10KTL-M0 ไม่มีแบตเตอรี่ จึงแสดงกล่องเส้นประ
- ถ้าขั้น 3 ตั้ง **Active power control = Zero export** เครื่องจำกัดกำลังไม่เกินโหลดบ้าน เส้นไปกริดเป็นสีเทา · ถ้าเลือกอย่างอื่นและกำลังผลิตเกินโหลด ส่วนเกินไหลออกกริด และถ้าผลิตน้อยกว่าโหลด เส้นกริดย้อนทิศเป็นการซื้อไฟ
- **ฝึกอ่านจากจอจริง** (กดขยาย): ภาพ SUN2000-10K-MAP0 แบบออนกริด มีแบตเตอรี่ 26% สร้างซ้ำจากหน้าจอแอปของระบบจริง 1 เครื่อง มีคำถาม 4 ข้อ (ทิศทางไหล, PV เทียบ AC, ทำไม PV1 เป็น 0, V × A สามเฟสรวมได้เท่าไร) และปุ่ม **เฉลย** ตัวเลข V × A รวม ≈ 1,389 W คำนวณจากค่าบนจอ
- หน้านี้เลียนแบบเพื่อการสอน ไม่ได้เชื่อมต่อ Huawei และจอจริงไม่แสดงสัดส่วนกริด/บ้านในระบบที่มีทั้งสองทาง

**ความผิดปกติที่ซ่อนอยู่**: ในขั้น 1 ผู้สอนเลือกได้ว่ารอบนี้มีสตริง 1 ขั้วกลับ, ต่ออนุกรมเกิน หรือฉนวน DC ต่ำ (หรือไม่มีเลย) ให้ผู้เรียนหาจากค่าที่วัด ถ้าเปิดเครื่องทั้งที่ยังไม่แก้ ขั้น 4 จะขึ้น alarm ตามชนิด (String Reverse Connection, High String Input Voltage, Low Insulation Resistance) พร้อมสาเหตุและวิธีแก้

**ข้อควรรู้**
- ค่า Quick settings ที่ผิดจะไม่ขึ้นเตือนบนเครื่องจริง หน้านี้จึงสรุปให้ตอนกดบันทึก เพื่อฝึกให้ผู้เรียนตรวจเอง
- LED ของ Dongle ในขั้น 5 ตรงกับตาราง 4-1 ในหน้า "คู่มือ (แปลไทย)" (เขียวติดค้าง = เชื่อมต่อสำเร็จ แดงกะพริบเร็ว = เชื่อมต่อเราเตอร์ไม่สำเร็จ)
- รหัสผ่านที่พิมพ์ไม่ถูกบันทึกไปกับโปรเจ็ค ส่วนความคืบหน้า (ขั้น ค่าที่วัด การตั้งค่า สวิตช์) ถูกบันทึกตามปกติ
- เกณฑ์ตัวเลข (ฉนวน ≥ 1 MΩ, AC 207–253 V ฯลฯ) เป็นเกณฑ์ของแบบฝึก งานจริงให้ตรวจกับคู่มือ Huawei, IEC 62446-1 และข้อกำหนดการไฟฟ้า

## สำหรับผู้สอน: สร้างฟอลต์
ส่วน **ครูสร้างฟอลต์** ตั้งช่วงที่เกิดฟอลต์ (ตั้งแต่ – ถึง) และรูปแบบ **ค่อยๆ เพิ่ม** หรือ **เกิดทันที** ให้ผู้เรียนหาสาเหตุจากกราฟและ alarm

## อ่าน log จากระบบจริง
เมนูย่อย **อ่าน log (นำเข้าไฟล์)** ใช้ไฟล์ที่ส่งออกจาก FusionSolar / SUN2000 / SmartLogger ดูผลผลิต แรงดัน กระแส กริด แบต และแจ้งเตือน ข้อมูลอ่านในเบราว์เซอร์เท่านั้น

### 1. ส่งออกไฟล์จาก Huawei (ชื่อเมนูอาจต่างตามเวอร์ชันแอป)
| ต้องการดู | ส่งออกจาก | ชนิดที่ระบบอ่านเป็น |
|---|---|---|
| ละเอียด 5 นาที (แรงดัน กระแสสตริง กำลัง) | FusionSolar → โรงไฟฟ้า → Devices → อินเวอร์เตอร์ → Historical data → เลือกค่า → Export | รายช่วงเวลา |
| รายชั่วโมงของวัน (Plant Report มุมมองวัน) | Report → รายงานโรงไฟฟ้า → เลือกวัน → ส่งออก | รายช่วงเวลา |
| รายวัน ในสัปดาห์ (≈ 7 แถว) หรือเดือน (≈ 30 แถว) | Report → รายงานโรงไฟฟ้า → มุมมองสัปดาห์/เดือน → ส่งออก | รายงานรายวัน |
| รายเดือน ในปี (12 แถว) | Report → รายงานโรงไฟฟ้า → มุมมองปี → ส่งออก | รายงานรายเดือน |
| แจ้งเตือน | Alarms → เลือกช่วงเวลา (รวมที่หายแล้ว) → ส่งออก | แจ้งเตือน |

### 2. นำเข้า
1. กด **เลือกไฟล์ log** (CSV / XLSX / XLS หลายไฟล์พร้อมกันได้) และกรอก **ขนาดติดตั้ง (kWp)** ถ้ารู้ · ฝึกก่อนด้วย **ใช้ข้อมูลตัวอย่าง** หรือ **ดาวน์โหลดไฟล์ตัวอย่าง CSV**
2. ชิปชื่อไฟล์แสดงชนิดที่ระบบเดาได้ (รายช่วงเวลา · รายวัน ดูรายสัปดาห์/เดือน · รายเดือน ดูทั้งปี · แจ้งเตือน) กด × เพื่อเอาไฟล์ออก
3. ถ้าหัวคอลัมน์จับคู่ผิด แก้ใน **ตรวจคอลัมน์ที่ระบบจับคู่** (ชนิดข้อมูล: อัตโนมัติ / รายช่วงเวลา / รายงานรายวัน-เดือน / แจ้งเตือน และหน่วย W/kW/Wh/kWh)
4. ไฟล์ Excel ของ Huawei ที่ระบุช่วงข้อมูลผิด (เช่น A4:M26) ระบบอ่านครบให้เอง · หัวเวลาแบบ 2026-W46 (สัปดาห์ ISO) อ่านได้

### 3. ดูผลของวัน (ไฟล์รายช่วงเวลา)
เลือก **วันที่** (และกรอก **พิกัดโรงไฟฟ้า** ข้างกันถ้าจะจำลอง ดูข้อ 5) แล้วดู
- **ตัวเลขสรุป** พลังงานที่ผลิต ผลผลิตจำเพาะ กำลังสูงสุด ช่วงที่ผลิตไฟ แรงดันสตริงสูงสุด ขาย/ซื้อไฟ ใช้ไฟ
- **ข้อสังเกตอัตโนมัติ**: clipping, ข้อมูลขาด, สตริงไม่เท่ากัน/เงาตอนเช้า, แรงดันกริดนอก 207–253 V, กริดหาย, อุณหภูมิสูง, SOC ต่ำ (เกณฑ์ประมาณ ไม่ใช่ผลวินิจฉัย)
- **กราฟ** กำลังไฟฟ้าตลอดวัน · แรงดันและกระแสสตริง · แรงดันกริด · SOC แบตและอุณหภูมิ (ช่วงที่มี alarm แสดงเป็นแถบสี)
- **รายการแจ้งเตือน** กรองระดับ (ร้ายแรง / เตือน / อื่นๆ) พร้อมระยะเวลาและแนวทางตรวจเบื้องต้นของรหัสที่พบบ่อย · **พลังงานรายวัน / รายเดือน** สำหรับไฟล์รายงาน
- **ส่งออก CSV ของวันนี้ (จัดเรียงแล้ว)** · **ล้างข้อมูลทั้งหมด**

### 4. กราฟวิเคราะห์ (เลือกเส้นเอง เปิด/ปิดได้)
ใช้ได้กับไฟล์ทุกชนิดที่มีคอลัมน์ตัวเลข (รวมคอลัมน์ที่ระบบไม่ได้จับคู่ เช่น PV3–PV12 ความถี่ กระแสเฟส) การ์ดแสดงแม้นำเข้าเฉพาะไฟล์รายวัน/รายเดือน
| ปุ่ม / ช่อง | ใช้ทำอะไร |
|---|---|
| ชื่อเส้น (แยกกลุ่มตามหน่วย) | กดเพื่อ **เปิด/ปิดเส้น** |
| กำลัง · แรงดัน · กระแส · อุณหภูมิ/SOC · ปิดทั้งหมด | เลือกชุดเส้นสำเร็จรูป |
| ช่วงข้อมูล | เฉพาะวันที่เลือก / ทุกวันที่นำเข้า (ไฟล์รายวันแสดงเมื่อเลือกทุกวัน ถ้านำเข้าเฉพาะไฟล์รายวันระบบเลือกให้) |
| สรุปข้อมูลรายวันเป็น | รายวัน / รายสัปดาห์ (จันทร์–อาทิตย์) / รายเดือน: kWh และ ฿ รวมกัน · กำลังสูงสุดเอาค่าสูงสุด · ค่าสะสม (Total Yield) เอาค่าท้าย · ค่าอื่น (อุณหภูมิ %) เฉลี่ย |
| แกน | ตามหน่วย (ซ้าย/ขวา ได้ 2 หน่วย) หรือปรับสเกลเทียบกัน (%) · เลือกเกิน 2 หน่วยระบบสลับเป็น % เอง |
| เลื่อนเมาส์/นิ้วบนกราฟ | อ่านค่าทุกเส้น ณ เวลานั้น |
| **ลากเลือกช่วงเวลา** | ตารางต่ำสุด / สูงสุด (เวลา) / เฉลี่ย / ต้น → ท้าย / พลังงานรวม (kWh) ของช่วงนั้น (คลิกที่กราฟเพื่อล้างช่วง) |
| ขยายช่วงที่เลือก · ล้างช่วง / กลับมุมมองทั้งหมด · ส่งออกสถิติ CSV | ซูมเข้า · กลับ · ดาวน์โหลดตารางสถิติ |

ข้อสังเกตของช่วงที่เลือก: ค่าแบนราบ (clipping) · ข้อมูลขาด · ค่าตกฉับพลัน · กระแสสตริงต่างกัน · เมื่อเปิดเพียง 2 เส้นแสดงสหสัมพันธ์ r และอัตราส่วนพลังงาน (เช่น AC ÷ DC ≈ ประสิทธิภาพอินเวอร์เตอร์) พลังงานรวม: เส้น W/kW อินทิเกรตตามเวลา · เส้น kWh/Wh ใช้ผลรวมของค่ารายช่วง (หรือผลต่างต้น→ท้ายถ้าเป็นค่าสะสม)

### 5. จำลองกรณีไม่เปิด Zero Export (ไม่จำกัดการส่งออก)
ตอบคำถามว่าถ้าปิดกันย้อน ระบบจะผลิตและเหลือใช้เท่าไร และจัดการส่วนที่เหลืออย่างไร ใช้ได้กับไฟล์รายช่วงเวลาที่มี PV Yield และ Import (ไฟล์รายวันแยกส่วนที่ถูกจำกัดไม่ได้)
1. กด **เปิดโหมดจำลอง** (หรือกรอก **พิกัดโรงไฟฟ้า** ข้างช่องวันที่ ระบบเปิดให้เอง) ได้เส้นประ 4 เส้น: PV ถ้าไม่จำกัดส่งออก · ส่วนที่ถูกจำกัด · ส่วนเหลือหลังโหลด · โหลด
2. ช่วงที่ซื้อไฟน้อยกว่าเกณฑ์ (ค่าตั้งต้น 0.35 kW) ถือว่าอินเวอร์เตอร์ถูกจำกัดกำลังให้ตามโหลด · ศักยภาพ = ค่าที่สูงกว่าระหว่างค่าจริงกับค่าจากโมเดล
3. **วิธีประเมิน** (เลือกได้ ระบบแสดงอีกวิธีให้เทียบ ช่วงจริงน่าจะอยู่ระหว่างสองค่า)
   - ปรับจากชั่วโมงที่ไม่ถูกจำกัด (ได้ค่าต่ำสุด)
   - ขนาดติดตั้ง × PR (ค่าสูงสุดที่เป็นไปได้ PR ตั้งต้น 0.80)
   - **จากพิกัดและวันที่ (จำลองแสงอาทิตย์)**: ใช้สูตรเดียวกับเมนู 07 ต้องมีพิกัดและ kWp ตั้งได้ มุมเอียง · ทิศหันแผง (180° = ใต้) · ท้องฟ้า · ความสูญเสียระบบ · พิกัด AC อินเวอร์เตอร์ · ปรับสเกลให้ตรงกับช่วงที่ไม่ถูกจำกัด (ตั้งต้นเปิด ชดเชยเมฆ/ฝุ่นของวันนั้น) · ใต้ช่องพิกัดแสดง Plus Code และเวลาดวงอาทิตย์ขึ้น–ตกเพื่อเทียบกับข้อมูลจริง
4. **ส่วนเหลือหลังโหลด** = ศักยภาพ − โหลด (โหลดจากคอลัมน์ Consumption หรือคำนวณจาก PV + Import − Export) สรุปแนวทางจัดการ
   - ตาราง **ขีดจำกัดส่งออก** 0 / 1 / 2 / 3 / 5 / 10 kW / ไม่จำกัด: ขายได้ · ตัดทิ้ง · รายได้ (ราคารับซื้อ ตั้งต้น 2.20 ฿/kWh แก้ได้)
   - **ย้ายโหลด**: ช่วงเวลาและกำลังเฉลี่ยที่เลื่อนโหลดมาใช้ในช่วงที่มีส่วนเหลือ
   - **แบตเตอรี่**: ขนาดโดยประมาณ (DoD 90%) และปริมาณที่เก็บไปแทนการซื้อไฟกลางคืน มูลค่าใช้ "ค่าไฟที่ซื้อ" ที่กรอก หรือคำนวณจาก Revenue ÷ PV Yield ในไฟล์
   - ถ้าเลือกดู "ทุกวันที่นำเข้า" จะสรุปรวมหลายวันและแสดงค่าเฉลี่ยต่อวัน
5. เป็นค่าประมาณจากข้อมูลที่นำเข้า ไม่ใช่ผลวัดจริง ควรดูหลายวันที่แดดดี · **การปิด Zero Export หรือขายไฟต้องเป็นไปตามข้อกำหนดและได้รับอนุญาตจากการไฟฟ้าก่อน**

## ใบงาน
**W13 อ่าน log Huawei FusionSolar** (ค่าเริ่ม = ปิด ผู้สอนเปิดที่ dashboard): นำเข้าไฟล์ log อย่างน้อย 1 ไฟล์ · คำถาม 2 ข้อ (พลังงานที่ผลิตได้และแจ้งเตือนที่พบ) · ส่งที่เมนู 18

**W14 Commissioning Huawei SUN2000** (ค่าเริ่ม = ปิด ผู้สอนเปิดที่ dashboard): ทำหน้า "Commissioning (ฝึกเปิดเครื่อง)" ให้ผ่านทุกข้อ เกณฑ์ตรวจอัตโนมัติ 5 ข้อ ได้แก่ ตรวจและวัดก่อนเปิดเครื่อง · เชื่อมต่อแอปและล็อกอิน · Quick settings · เปิดเครื่องถึง On-grid · ตรวจหลังเดินเครื่อง (เช็กลิสต์แสดงจำนวนข้อที่ผ่านของแต่ละกลุ่ม) · คำถาม 3 ข้อ (ความผิดปกติที่พบจากค่าที่วัด · เหตุผลที่ต้องเปิด AC ก่อน DC และเลือก Grid code ให้ตรงเขต · ความหมายของ LED แดงกะพริบเร็ว) · ส่งที่เมนู 18 ผลอยู่ในเครื่องที่ส่งงาน ถ้าผู้เรียนกด **เริ่มใหม่** เกณฑ์จะกลับเป็นยังไม่ผ่าน
