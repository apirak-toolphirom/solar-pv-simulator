# เมนู 07 จำลองแผง

**ฉบับ 1.0 · ปรับปรุงล่าสุด 5 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/solar.js`

จำลองกำลังผลิตทั้งวันตามพิกัด วันที่ มุมเอียง และทิศของแผง ใช้แผงที่ต่อสายไว้ในเมนู 03

**ใครใช้ได้**: ค่าเริ่ม auto (ใบงาน W3)

## ก่อนเริ่ม
ต่อสายแผงเข้า MPPT ให้ครบวงจรและผ่านการตรวจขั้วในเมนู 03 ก่อน จึงจะจำลองได้

## ขั้นตอน
1. **พิกัดไซต์**: Plus Code หรือ ละติจูด, ลองจิจูด
2. **วันที่** และ **เขตเวลา (UTC+)** (ไทย = 7)
3. **สภาพท้องฟ้า**: ฟ้าใส / เมฆบางส่วน / ฟ้าปิดหรือฝน
4. **อุณหภูมิอากาศต่ำสุด / สูงสุดของวัน**
5. **มุมเอียงแผง** และ **ทิศที่แผงหันหน้าไป** (0° = เหนือ, 90° = ตะวันออก, 180° = ใต้) หรือกด **ตั้งมุมและทิศตามละติจูด**
6. ติ๊ก **คิดเงาบนแผงจากผังไซต์** เพื่อใช้เงาจากต้นไม้และตึกในเมนู 08 (**ไปแท็บไซต์และเงา**)

> หน้าจอบางจุดยังเรียกเมนูไซต์และเงาว่า "แท็บ 05" (เลขเดิมก่อนจัดกลุ่มเมนู) หมายถึงเมนู 08

## อ่านผล
- **กำลังไฟฟ้าตลอดวัน** กราฟกำลัง DC/AC
- **แรงดันสตริงเทียบช่วง MPPT** ดูว่าแรงดันอยู่ในช่วงทำงานตลอดวันหรือไม่
- **เทียบทิศที่วางแผง** พลังงานต่อวันเมื่อหันทิศต่างกัน
- **มุมมองไซต์ Top / Side view**
- **ตารางรายชั่วโมง** (แตะเพื่อเปิด)

## วิธีคำนวณ
แบบจำลองแสงอาทิตย์อย่างง่าย · อุณหภูมิเซลล์จาก NOCT ของแผง (ไม่ระบุใช้ 43°C) · สูญเสียอื่น 5% · ประสิทธิภาพอินเวอร์เตอร์ตามรุ่น · ไม่รวมเงาบังถ้าไม่ได้ติ๊กใช้ผังไซต์ · ใช้วางแผนเบื้องต้น ไม่ใช่ค่ารับประกัน

## ใบงาน W3
จำลองแผงแล้ว · วางแผงบนผังเมนู 08 · ใช้เงาจากผัง · เงาบัง ≤ 15%
