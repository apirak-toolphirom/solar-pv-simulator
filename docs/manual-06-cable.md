# เมนู 06 สายไฟและเบรกเกอร์

**ฉบับ 1.2 · ปรับปรุงล่าสุด 9 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ `js/cable.js`

เลือกขนาดสาย เบรกเกอร์ ฟิวส์ สายดิน แรงดันตก และท่อร้อยสาย ทั้งฝั่ง AC และ DC ใช้ค่าอุปกรณ์จากเมนู 02–03 ได้ บันทึกค่าไปกับโปรเจ็ค

**ใครใช้ได้**: ค่าเริ่ม เปิด ให้ผู้เรียน · ผู้เยี่ยมชมเห็นเมื่อผู้สอนติ๊ก

## หน้าย่อย
| หน้า | ใช้ทำอะไร |
|---|---|
| AC: สาย + เบรกเกอร์ | ขาออกอินเวอร์เตอร์จากเมนู 02 (กระแสที่ 220 / 380 V × 1.25) หรือโหลดทั่วไป (kW / kVA / A, 1/3 เฟส) → เบรกเกอร์ (MCB/MCCB, curve, ขั้ว, Icu) RCD สายเฟส N PE แรงดันตก ท่อ/รางเดินสาย ตารางเทียบทุกขนาดสาย |
| DC: สตริงแผง | ดึงแผงและจำนวนอนุกรม/ขนานจากเมนู 02–03 → Voc สูงสุดตอนเย็น ฟิวส์สตริง gPV (เมื่อ (Np−1)·Isc เกินพิกัดฟิวส์ของแผง) สาย PV สตริงและสายรวม เบรกเกอร์/สวิตช์ DC SPD |
| DC: แบตเตอรี่ | ดึงแบตและอินเวอร์เตอร์จากเมนู 02 → กระแสสูงสุด ฟิวส์ class T / เบรกเกอร์ DC พิกัดตัดกระแส สายแบต แรงดันตก |
| เลือกเบรกเกอร์ AC / DC | หาพิกัดเบรกเกอร์เร็วๆ จาก kW หรือ A (AC) หรือ PV / แบต / โหลด DC 12–48 V · ลิงก์ "อ่านเรื่อง curve" ไปเมนู 01 |
| ตารางอ้างอิง | พิกัดกระแสสาย PVC / XLPE / PV ตัวคูณอุณหภูมิ ตัวคูณจัดกลุ่ม และสูตรที่ใช้ |

## ขั้นตอนทั่วไป
1. เลือกหน้าย่อย
2. เลือกแหล่งค่า (จากอุปกรณ์ในเมนู 02–03 หรือกรอกเอง)
3. ตั้งวิธีติดตั้ง ความยาวสาย อุณหภูมิ จำนวนวงจรในท่อ
4. อ่านขนาดสาย เบรกเกอร์ แรงดันตก และข้อเตือน

## มาตรฐานอ้างอิง
IEC 60364-5-52 (ทองแดง) · EN 50618 (สายโซลาร์) · สายดิน IEC 60364-5-54 ตาราง 54.2 · หลัก IEC 62548 แบบย่อ · งานจริงต้องตรวจกับ วสท. ฉบับที่ใช้บังคับ ข้อกำหนดการไฟฟ้า และดาต้าชีตผู้ผลิต

## ใบงาน
**W9 สายไฟและเบรกเกอร์** (ค่าเริ่ม = ปิด ผู้สอนเปิดที่ dashboard): ปรับค่าเองในหน้าย่อยอย่างน้อย 2 หน้า (AC · DC แผง · DC แบต · เบรกเกอร์) และผลของหน้านั้นไม่มีข้อไม่ผ่าน ค่าเริ่มที่ยังไม่แก้ไม่นับ · คำถาม 2 ข้อ · ส่งที่เมนู 18

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| หน้า DC ไม่มีค่าแผง | ยังไม่ได้ต่อสายในเมนู 03 หรือยังไม่เลือกแผงในเมนู 02 |
| แรงดันตกเกิน | เพิ่มขนาดสาย หรือลดความยาว |
