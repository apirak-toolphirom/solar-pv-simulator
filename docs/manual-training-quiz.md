# คู่มือระบบสอบ Pre-test / Post-test (Apps Script)

**ฉบับ 1.0 · ปรับปรุงล่าสุด 13 พ.ย. 2569** · [กลับสารบัญ](README.md) · ไฟล์ที่เกี่ยวข้อง `apps-script/quiz/` · [แผนการสอนรายวัน](training-lesson-plans.md)

ระบบสอบออนไลน์สำหรับหลักสูตรโซลาร์เซลล์ครัวเรือน 20 วัน (28 พ.ย. 69 – 28 ก.พ. 70) ข้อสอบ **20 ข้อต่อวัน** เลือกตอบ 4 ตัวเลือก ใช้ชุดเดียวกันทั้ง Pre และ Post เพื่อวัดพัฒนาการ

| | Pre-test (ก่อนเรียน) | Post-test (หลังเรียน) |
|---|---|---|
| เก็บอีเมล ชื่อ กลุ่ม | ใช่ | ใช่ |
| แจ้งคะแนน | ใช่ (บนหน้าจอ) | ใช่ (บนหน้าจอ) |
| บอกข้อถูก/ผิด | **ไม่บอก** | **บอก** (และเฉลยข้อที่ผิด ปิดได้) |
| ส่งอีเมลผล | ไม่ส่ง (เปิดได้ที่ `SEND_PRE_EMAIL`) | **ส่ง** พร้อมคะแนน รายข้อ และพัฒนาการเทียบ Pre |

เฉลยอยู่ฝั่งเซิร์ฟเวอร์เท่านั้น ข้อมูลที่ส่งไปที่เบราว์เซอร์ผู้เรียนไม่มีเฉลย ระบบสลับลำดับข้อและตัวเลือกให้ทุกครั้ง

## ไฟล์ในโฟลเดอร์ `apps-script/quiz/`
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ระบบหลัก: เริ่มสอบ ตรวจข้อสอบ บันทึกชีต ส่งอีเมล ค่าตั้ง `CONFIG` |
| `Index.html` | หน้าสอบสำหรับผู้เรียน (ใช้บนมือถือได้) |
| `appsscript.json` | สิทธิ์และการ deploy |
| `QuestionBank.sample.gs` | ตัวอย่างโครงสร้างข้อสอบ 2 ข้อ |
| `QuestionBank.gs` | **ข้อสอบจริงพร้อมเฉลย 400 ข้อ (ไม่อยู่ใน repo สาธารณะ)** ผู้สอนเก็บไว้เอง วางในโปรเจกต์ Apps Script เท่านั้น |

> repo นี้เป็นสาธารณะ จึงไม่เก็บข้อสอบจริงและเฉลยไว้ที่นี่ ถ้าเผยแพร่ ผู้เรียนจะเปิดอ่านเฉลยได้

## ติดตั้ง (ผู้สอนทำครั้งเดียว)
1. เปิด [script.google.com](https://script.google.com) → **โปรเจกต์ใหม่** ตั้งชื่อเช่น "ระบบสอบโซลาร์ครัวเรือน"
2. สร้างไฟล์ให้ตรงชื่อ แล้ววางเนื้อหา: `Code.gs` · `QuestionBank.gs` (ไฟล์ข้อสอบจริง) · `Index.html` (ชนิด HTML)
3. เปิด **Project Settings → Show "appsscript.json" manifest file** แล้ววางเนื้อหา `appsscript.json`
4. ถ้าต้องการจำกัดโดเมนอีเมล (เช่น `['ubu.ac.th']`) หรือให้ผู้สอนรับสำเนาผล แก้ `CONFIG` ที่หัวไฟล์ `Code.gs`
5. เลือกฟังก์ชัน **`setup`** แล้วกด **Run** อนุญาตสิทธิ์ (Sheets, ส่งอีเมล) ระบบสร้างสเปรดชีตผลสอบพร้อมชีต `Settings` `Results` `Summary` ดู URL ได้ที่ Execution log
6. **Deploy → New deployment → Web app**: Execute as = **Me**, Who has access = **Anyone** (หรือ Anyone within องค์กร ถ้าทุกคนใช้บัญชีโดเมนเดียวกัน) แล้วคัดลอก URL ของเว็บแอป
7. ทุกครั้งที่แก้ `Code.gs`/`Index.html`/ข้อสอบ ต้อง **Deploy → Manage deployments → Edit → New version**

## วันสอบ: เปิด/ปิดข้อสอบ
- ชีต **Settings** มีทุกวันและช่องติ๊ก **เปิด Pre-test** / **เปิด Post-test** ค่าเริ่มต้น **ปิดทั้งหมด**
- เวลา 09.00 ติ๊ก Pre-test ของวันนั้น → ผู้เรียนสอบ → เวลา 15.30 ติ๊ก Post-test (ควรเอา Pre ออกเมื่อหมดเวลา)
- ไม่เปิด Post ล่วงหน้า เพราะ Post บอกเฉลยข้อที่ผิด
- ลิงก์ตรงเข้าหน้าฟอร์ม: `URL?day=3&type=pre` และ `URL?day=3&type=post` (ทำเป็น QR ให้ผู้เรียนสแกนได้)

## สิ่งที่ผู้เรียนเห็น
1. เลือกวันและประเภท (หรือเข้าด้วยลิงก์ตรง) → กรอก **ชื่อ-สกุล · กลุ่ม (1–10) · อีเมล**
2. ทำ 20 ข้อ แถบแสดงจำนวนที่ตอบแล้ว ส่งแล้วแก้ไม่ได้
3. Pre: เห็นคะแนนอย่างเดียว · Post: เห็นคะแนน ข้อถูก/ผิด (ข้อที่ผิดมีเฉลย) พัฒนาการเทียบ Pre และได้รับอีเมลผล
4. ถ้าบัญชี Google อยู่โดเมนเดียวกับผู้สอน ระบบใช้อีเมลจากบัญชีโดยอัตโนมัติ (แก้ไม่ได้) ถ้าเป็นบัญชีภายนอก ใช้อีเมลที่พิมพ์

## ชีตผล
| ชีต | เนื้อหา |
|---|---|
| `Results` | 1 แถวต่อ 1 ครั้งสอบ: เวลา วัน หัวข้อ ประเภท อีเมล ชื่อ กลุ่ม คะแนน เต็ม % เวลาที่ใช้ ครั้งที่ และคำตอบ (JSON) |
| `Settings` | ติ๊กเปิด/ปิด Pre/Post รายวัน |
| `Summary` | จำนวนผู้สอบ คะแนนเฉลี่ย Pre/Post และพัฒนาการ ต่อวัน (สูตรอัปเดตเอง) |

หา **คะแนนเฉลี่ยรายกลุ่ม**: ใน `Results` ทำ Pivot โดยแถว = กลุ่ม คอลัมน์ = ประเภท ค่า = เฉลี่ยของคะแนน

## ค่าตั้งใน `CONFIG`
| ค่า | ค่าเริ่ม | ความหมาย |
|---|---|---|
| `PRE_MAX_ATTEMPTS` / `POST_MAX_ATTEMPTS` | 1 / 1 | จำนวนครั้งสูงสุดต่ออีเมลต่อวัน |
| `SEND_PRE_EMAIL` | false | ส่งคะแนน Pre ทางอีเมลด้วย |
| `SEND_POST_EMAIL` | true | ส่งผลละเอียด Post ทางอีเมล |
| `SHOW_CORRECT_ON_POST` | true | แสดงเฉลยของข้อที่ตอบผิดใน Post |
| `ALLOWED_EMAIL_DOMAINS` | ว่าง | จำกัดโดเมนอีเมล |
| `CC_INSTRUCTOR` | ว่าง | อีเมลผู้สอนรับสำเนาผล Post |
| `GROUP_COUNT` | 10 | จำนวนกลุ่ม workshop |

## ข้อจำกัดและข้อควรรู้
- โควตาส่งอีเมลของ Apps Script: บัญชี Gmail ทั่วไปประมาณ 100 ฉบับ/วัน บัญชี Workspace ประมาณ 1,500 ฉบับ/วัน (ตรวจโควตาปัจจุบันของ Google อีกครั้ง) ผู้เรียน ~40 คนใช้ Post วันละ ~40 ฉบับ จึงพอ ถ้าส่งไม่สำเร็จ ผลยังถูกบันทึกและแสดงบนหน้าจอ
- ใช้ชุดข้อสอบเดียวกัน Pre/Post ผู้เรียนที่จำข้อสอบได้จะได้เปรียบ ถ้าต้องการสองชุด ให้เพิ่มวันใหม่ใน `QuestionBank.gs` สำหรับ Post
- ถ้ากด "ส่ง" แล้วเน็ตหลุด ให้ตรวจชีต `Results` ก่อนอนุญาตสอบซ้ำ (ลบแถวนั้นหรือเพิ่ม `*_MAX_ATTEMPTS` ชั่วคราว)
- ข้อสอบเน้นแนวคิดและโจทย์คำนวณพื้นฐาน เมื่อพบรายละเอียดมาตรฐาน วสท. หรือข้อกำหนดการไฟฟ้าที่เปลี่ยน ให้ตรวจกับฉบับจริงก่อนใช้
- ระบบนี้แยกจาก `QuizForm.gs` (ตัวสร้าง Google Form pretest เดิม) ใช้ร่วมกันหรือเลือกอย่างใดอย่างหนึ่งได้

| อาการ | วิธีแก้ |

| "ยังไม่เปิดหรือปิดแล้ว" | ติ๊กช่องเปิดของวันนั้นในชีต Settings |
