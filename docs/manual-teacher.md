# คู่มือผู้สอน

**ฉบับ 1.1 · ปรับปรุงล่าสุด 9 พ.ย. 2569** · [กลับสารบัญ](README.md) · รายละเอียดการตั้งค่าเชิงเทคนิค: [`apps-script/README.md`](../apps-script/README.md)

## 1. ตั้งระบบรับงาน (ครั้งเดียวต่อรุ่นอบรม ~10 นาที)
1. สร้าง Google Sheets ใหม่ เช่น `ผลส่งงานโซลาร์ รุ่น 1` → **ส่วนขยาย → Apps Script** → วางโค้ดจาก `apps-script/Code.gs` แล้วบันทึก
2. **Project Settings → Script properties** เพิ่ม
   - `CLASS_CODE` รหัสห้องที่บอกผู้เรียน
   - `TEACHER_CODE` รหัสผู้สอน (คนละค่ากับ CLASS_CODE)
   - `DRIVE_FOLDER_ID` (ไม่บังคับ) โฟลเดอร์ Drive เก็บโปรเจ็คและภาพงานส่งของผู้เรียน
   - `GOOGLE_CLIENT_ID` (ไม่บังคับ) ถ้าต้องการปุ่ม Google Sign-in
3. **Deploy → New deployment → Web app** · Execute as: Me · Who has access: Anyone → คัดลอก URL ที่ลงท้าย `/exec`
4. ใส่ URL ใน `js/config.js` ที่ `SUBMIT_URL` → `python3 build.py` → commit + push

> แก้ `Code.gs` ทุกครั้ง ต้อง **Deploy → Manage deployments → Edit → New version** URL เดิมจึงใช้โค้ดใหม่ (เช่น เมื่อมีเมนูใหม่ แผ่น "เมนู" จะเพิ่มแถวให้หลัง Deploy)

ชีตที่ระบบสร้างให้เอง: **Submissions** (งานส่ง) · **ใบงาน** · **เมนู** · **รายชื่อ**

## 2. หน้าสรุปงานส่ง (dashboard.html)
เปิด `https://apirak-toolphirom.github.io/solar-pv-simulator/dashboard.html` กรอกรหัสผู้สอน กด **โหลดข้อมูล** (กด **ดูข้อมูลตัวอย่าง** เพื่อดูหน้าตาโดยไม่ต้องตั้งค่า)

| ส่วน | ใช้ทำอะไร |
|---|---|
| ความคืบหน้าใบงาน | ตารางผู้เรียน × ใบงาน (ครั้งล่าสุดของแต่ละคน) |
| ตั้งค่าใบงาน (เปิด / ปิดรับ) | เลือก auto / เปิด / ปิด ต่อใบงาน |
| ตั้งค่าเมนู (สิทธิ์ผู้เรียน / ผู้เยี่ยมชม) | เปิด/ปิดเมนูรายเมนู ดูข้อ 3 |
| จำนวนงานส่งรายวัน · ผลการตรวจ · ข้อผิดพลาดที่พบบ่อย | ภาพรวมทั้งห้อง |
| รายชื่อผู้ส่งงาน | กรองวัน ผล ค้นหา · ติ๊ก "เฉพาะครั้งล่าสุดของแต่ละคน" · **ส่งออก CSV** |

ติ๊ก **อัปเดตทุก 1 นาที** เพื่อดูงานส่งแบบสดระหว่างคาบ · รหัสผู้สอนจำไว้เฉพาะแท็บที่เปิดอยู่ ปิดแท็บแล้วกรอกใหม่

## 3. เปิด/ปิดเมนู
ส่วน **ตั้งค่าเมนู** ใน dashboard (หรือแก้ในแผ่น "เมนู" ของชีต) มีผลทันที ผู้เรียนรีเฟรชหน้าเพื่อเห็น

| สถานะ | ผล |
|---|---|
| auto | เปิดเมื่อมีใบงานที่ใช้เมนูนั้นเปิดรับอยู่ ไม่มีก็ซ่อน · เมนู 16 ส่งงาน auto = เปิดเมื่อมีใบงานเปิดอยู่ |
| เปิด | ผู้เรียนใช้ได้ |
| ดูอย่างเดียว | ผู้เรียนเห็นแต่แก้ไม่ได้ |
| ปิด | ซ่อนจากผู้เรียน |

ติ๊ก **ผู้เยี่ยมชมเห็น** เพื่อให้คนที่ไม่ลงชื่อเห็นเมนูนั้น (เมนู 15 ส่วนอ่าน log ผู้เยี่ยมชมไม่เห็นเสมอ)

ค่าเริ่ม: 01 คลังความรู้ และ 06 สายไฟและเบรกเกอร์ = เปิด · 13 Solis, 14 LiFePO4, 17 คำนวณความคุ้มค่า, 18 ออกแบบระบบไฟฟ้า วสท. = ปิด (เปิดเองเมื่อถึงคาบ) · อื่นๆ = auto · ผู้เยี่ยมชมเห็น 00 และ 10

## 4. ใบงาน
แผ่น **ใบงาน** (แก้ชื่อ วันที่ เกณฑ์ คำถาม ภาพได้ในชีต สถานะแก้ใน dashboard ได้)

| ใบงาน | เมนู | เกณฑ์ผ่านอัตโนมัติ |
|---|---|---|
| W00 แบบฝึกพื้นฐาน 15 หัวข้อ | 00 | ผ่านครบ 15 หัวข้อ |
| W1 อุปกรณ์และต่อสาย DC | 02, 03 | ต่อสาย DC ผ่าน · แผง ≥ 8 · DC/AC 0.9–1.5 |
| W2 ต่อสาย AC และพอร์ตอินเวอร์เตอร์ | 04 | ต่อสาย AC ผ่าน |
| W3 กำลังผลิตและเงา | 07, 08 | จำลองแผงแล้ว · วางแผงบนผัง · ใช้เงาจากผัง · เงาบัง ≤ 15% |
| W4 โหลดและ Backup | 09, 10 | โหลด ≥ 5 รายการ · ไฟดับ ≥ 6 ชม. · Backup จ่ายพอ |
| W5 เลือกระบบ | 11 | เปิดดูระบบ |
| W6 จำลองเหตุการณ์ | 12 | ลองเหตุการณ์อย่างน้อย 1 อย่าง |
| W7 วงจร DC 12/24/48 V | 05 | ผ่านการตรวจวงจร |
| W8 Commissioning Solis Hybrid | 13 | ผ่านครบ 1 ระบบ · หาข้อผิดพลาดถูก 1 โจทย์ (ค่าเริ่ม = ปิด) |
| W0 ส่งรวม | ทุกเมนู | — |

- สถานะ `auto` = เปิดรับตามวันที่เปิด–ปิด (ว่าง = ไม่จำกัด) · ใบงานที่ปิดรับ ผู้เรียนส่งไม่ได้
- คำถามคั่นด้วย `|` ผู้เรียนต้องตอบข้อละ ≥ 10 ตัวอักษร
- ภาพ (`dc` `ac` `site` `bench` `none`) เก็บในโฟลเดอร์ "ภาพงานส่ง" ใต้ `DRIVE_FOLDER_ID`
- เกณฑ์ที่ใช้ได้ทั้งหมดดู `apps-script/README.md` ข้อ 9

## 5. รายชื่อลงทะเบียน
แผ่น **รายชื่อ** คอลัมน์ `รหัสผู้เรียน | ชื่อ-นามสกุล | อีเมล Google | สถานะ` · ใส่ `ระงับ` เพื่อปิดสิทธิ์รายคน · แผ่นว่าง = ไม่ตรวจรายชื่อ (ใช้รหัสห้องอย่างเดียว) · ใช้ชีตจากไฟล์อื่นได้ด้วย `ROSTER_SHEET_ID` / `ROSTER_SHEET_NAME`

## 6. แก้รุ่นอุปกรณ์
- เมนู 02 → **ปลดล็อกผู้สอน** (กรอก TEACHER_CODE) หรือเข้าโหมดผู้สอน แล้วเพิ่ม แก้ไข ลบ นำเข้า (PDF / JSON / CSV) ได้
- การแก้ในหน้าเว็บมีผลเฉพาะเบราว์เซอร์นั้น รุ่นที่ต้องการให้ทุกเครื่องเห็น ใส่ใน `BUILTIN` ของ `js/catalog.js` แล้ว build + push

## 7. แบบทดสอบ Google Form
`apps-script/QuizForm.gs` สร้างแบบทดสอบจากคำถามเมนู 00 (วันเสาร์ หัวข้อ 01–07, วันอาทิตย์ 08–15 วันละ 20 ข้อ มีเฉลย) · script.google.com → New project → วางไฟล์ → Run `createBothQuizzes` · Pre/Post-test: `createAllPrePost` · แก้คำถามใน `js/basics.js` แล้วต้องสร้างฟอร์มใหม่

## 8. อัปเดตเว็บ
แก้ไฟล์ต้นทาง → `python3 build.py` → commit + push → GitHub Pages อัปเดตภายในไม่กี่นาที หน้าเว็บบนมือถือจะโหลดเวอร์ชันใหม่เอง

## 9. ข้อมูลที่เก็บ
หนึ่งแถวต่อการกดส่งงาน: ชื่อ รหัส รหัสห้อง เวลา ใบงาน ผลตามเกณฑ์ คำตอบ ผลตรวจการต่อสาย รุ่นอุปกรณ์ ตัวเลขสรุปจำลอง และภาพ ไม่เก็บทุกการลากสาย · แจ้งผู้เรียนว่าเก็บอะไร และลบชีตเมื่อจบรุ่น

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| เมนูใหม่ไม่ขึ้นในตาราง dashboard | วาง `Code.gs` ล่าสุด แล้ว Deploy → New version |
| ผู้เรียนส่งงานไม่ได้ | ใบงานปิดรับ · รหัสห้องผิด · รายชื่อไม่ตรงหรือถูกระงับ |
| ปุ่มส่งงานปิดอยู่ | ยังไม่ได้ใส่ `SUBMIT_URL` ใน `js/config.js` |
| dashboard แจ้งรหัสผู้สอนไม่ถูกต้อง | ตรวจ `TEACHER_CODE` ใน Script properties |
| ไม่มีภาพงานส่ง | ยังไม่ได้ตั้ง `DRIVE_FOLDER_ID` หรือใบงานตั้งภาพเป็น `none` |
