# คู่มือผู้สอน

**ฉบับ 1.16 · ปรับปรุงล่าสุด 12 พ.ย. 2569** · [กลับสารบัญ](README.md) · รายละเอียดการตั้งค่าเชิงเทคนิค: [`apps-script/README.md`](../apps-script/README.md)

## 1. ตั้งระบบรับงาน (ครั้งเดียวต่อรุ่นอบรม ~10 นาที)
1. สร้าง Google Sheets ใหม่ เช่น `ผลส่งงานโซลาร์ รุ่น 1` → **ส่วนขยาย → Apps Script** → วางโค้ดจาก `apps-script/Code.gs` แล้วบันทึก
2. **Project Settings → Script properties** เพิ่ม
   - `CLASS_CODE` รหัสห้องที่บอกผู้เรียน
   - `TEACHER_CODE` รหัส **admin** (ทำได้ทุกอย่าง) คนละค่ากับ CLASS_CODE · **เฉพาะ admin ที่กรอกรหัส** ครูคนอื่นเข้าด้วยอีเมล Google ตามข้อ 1.1
   - `DRIVE_FOLDER_ID` (ไม่บังคับ) โฟลเดอร์ Drive เก็บโปรเจ็คและภาพงานส่งของผู้เรียน
   - `GOOGLE_CLIENT_ID` (ไม่บังคับ) เปิดโหมดเข้มของข้อ 5: ผู้เรียนเข้าด้วย Google และอีเมลต้องอยู่ในรายชื่อ (ใส่ค่าเดียวกันใน `js/config.js` ด้วย)
3. **Deploy → New deployment → Web app** · Execute as: Me · Who has access: Anyone → คัดลอก URL ที่ลงท้าย `/exec`
4. ใส่ URL ใน `js/config.js` ที่ `SUBMIT_URL` → `python3 build.py` → commit + push

> แก้ `Code.gs` ทุกครั้ง ต้อง **Deploy → Manage deployments → Edit → New version** URL เดิมจึงใช้โค้ดใหม่ (เช่น เมื่อมีเมนูใหม่ แผ่น "เมนู" จะเพิ่มแถวให้หลัง Deploy)

ชีตที่ระบบสร้างให้เอง: **Submissions** (งานส่ง) · **ใบงาน** · **เมนู** · **รายชื่อ**

หัวคอลัมน์ของ Submissions ถูกแก้ให้ตรงกับเวอร์ชันล่าสุดเองทุกครั้งที่มีการส่งงาน เปิด dashboard หรือผู้เรียนดูประวัติใบงาน (ชีตที่ใช้มาหลายเวอร์ชันมีหัวสั้นกว่า) สั่งเองได้จากเมนู **⚡ ระบบโซลาร์ (ผู้สอน) → ซ่อมหัวคอลัมน์ Submissions** ในชีต (เมนูนี้โผล่หลังโหลดชีตใหม่) ข้อมูลเดิมไม่ถูกแตะ และจะไม่แก้ถ้าช่อง A1 ไม่ใช่ "เวลาที่รับ"

## 1.1 บัญชีครู (ไม่ใช่ admin) เข้าด้วยอีเมล Google
ครูหลายคนใช้งานได้โดย **ไม่ต้องกรอกรหัส** แค่กด **Sign in with Google** ด้วยอีเมลที่ admin ใส่ไว้ · ครู **เปิดเมนูและเนื้อหาได้ ทำแบบทดสอบได้ เปิด/ปิดใบงานได้ ดู dashboard และรายชื่อได้ แต่ไม่มีสิทธิ์แก้หรือลบข้อมูล** · **เฉพาะ admin ที่กรอกรหัส**

| ทำอะไร | admin (กรอก `TEACHER_CODE`) | ครู (เข้าด้วยอีเมล Google) |
|---|---|---|
| เห็นและทำทุกเมนู รวมแบบทดสอบ เมนู 00 และใบงาน | ได้ | ได้ |
| ดู dashboard สรุปงานส่งและรายชื่อ | ได้ | ได้ |
| เปิด/ปิดเมนู เปลี่ยนสถานะ auto / เปิด / ดูอย่างเดียว / ปิด | ได้ | ได้ |
| เปิด/ปิดใบงาน (auto / เปิด / ปิด) | ได้ | ได้ |
| นำเข้า เพิ่ม หรือแก้รายชื่อผู้เรียน | ได้ | **ไม่ได้** |
| เพิ่ม แก้ไข ลบ นำเข้ารุ่นอุปกรณ์ (เมนู 02) | ได้ | **ไม่ได้** |
| เพิ่ม/ปิดครู (แก้แผ่น "ครู") | ได้ | **ไม่ได้** |

**ก่อนเริ่ม:** ต้องตั้ง `GOOGLE_CLIENT_ID` ใน Script properties และใน `js/config.js` แล้ว (ดูข้อ 5) เพราะระบบตรวจอีเมลกับ Google ทุกครั้ง

**วิธีเพิ่มครู** (admin ทำ)
1. เปิด Google Sheets ของระบบ → เมนู **⚡ ระบบโซลาร์ (ผู้สอน) → สร้างแผ่นครู (อีเมลครู)** (ครั้งแรกอาจต้องกดอนุญาตสิทธิ์) จะได้แผ่น **ครู**
2. กรอก **ชื่อครู** (คอลัมน์ A) และ **อีเมลครู** (คอลัมน์ B เป็นบัญชี Google ที่ครูใช้ เช่น `ชื่อ@ubu.ac.th`)
3. ใช้ได้ทันที **ไม่ต้อง Deploy ใหม่** · เลิกใช้ให้ตั้งคอลัมน์ **สถานะ** เป็น `ปิด` (หรือลบแถว)
4. **ครูเข้าอย่างไร:** ในโปรแกรมกดปุ่ม **Sign in with Google** เหมือนผู้เรียน ระบบจะรู้ว่าเป็นครูและเปิดทุกเมนูให้ · ที่ `dashboard.html` กดปุ่ม **Sign in with Google** ได้เลย ไม่ต้องกรอกช่องรหัส

อีเมลที่ไม่อยู่ในแผ่น "ครู" จะเข้าเป็นผู้เรียนตามปกติ (ต้องอยู่ในรายชื่อผู้เรียน)

## 3. เปิด/ปิดเมนู
ส่วน **ตั้งค่าเมนู** ใน dashboard (หรือแก้ในแผ่น "เมนู" ของชีต) มีผลทันที ผู้เรียนรีเฟรชหน้าเพื่อเห็น

| สถานะ | ผล |
|---|---|
| auto | เปิดเมื่อมีใบงานที่ใช้เมนูนั้นเปิดรับอยู่ ไม่มีก็ซ่อน · เมนู 21 ส่งงาน auto = เปิดเมื่อมีใบงานเปิดอยู่ |

ติ๊ก **ผู้เยี่ยมชมเห็น** เพื่อให้คนที่ไม่ลงชื่อเห็นเมนูนั้น (เมนู 17 ส่วนอ่าน log ผู้เยี่ยมชมไม่เห็นเสมอ)

## 5. รายชื่อผู้เรียนและการเข้าระบบด้วย Google
**โหมดเข้ม (แนะนำ)** เปิดเมื่อตั้ง `GOOGLE_CLIENT_ID` (ทั้ง `js/config.js` และ Script properties)
- ผู้เรียนกดปุ่ม **Sign in with Google** บนแถบด้านบน ระบบรับเฉพาะอีเมลที่ Google ยืนยันแล้ว **และอยู่ในแผ่น "รายชื่อ"** (สถานะไม่ใช่ `ระงับ`) ใครมีบัญชี Google ก็เข้าไม่ได้ถ้าอีเมลไม่อยู่ในรายชื่อ
- ชื่อและรหัสของผู้เรียนมาจากรายชื่อ ไม่ต้องกรอก และไม่ใช้รหัสห้อง (`CLASS_CODE` ไม่ถูกถาม) รายชื่อว่าง = ไม่มีใครเข้าได้
- รหัสผู้เรียนอย่างเดียวเข้าไม่ได้ ผู้เรียนต้องมีบัญชี Google (Gmail หรืออีเมลมหาวิทยาลัยที่เป็น Google)
- Google ต่ออายุสิทธิ์ทุกชั่วโมง ระบบต่ออายุให้เงียบๆ ถ้าเด้งว่า "ต้องเข้าสู่ระบบด้วยบัญชี Google" ให้กดปุ่มอีกครั้ง
- ตั้ง `GOOGLE_CLIENT_ID`: Google Cloud Console → Credentials → OAuth client ID (Web application) → Authorized JavaScript origins ใส่ `https://apirak-toolphirom.github.io` (รายละเอียดใน `apps-script/README.md` ข้อ 5) แล้ววางค่าใน `js/config.js`, build, push

**โหมดเดิม** (ไม่ตั้ง `GOOGLE_CLIENT_ID`): ผู้เรียนกรอกชื่อ · รหัสผู้เรียน · รหัสห้อง ตรวจกับรายชื่อ (แผ่นว่าง = ตรวจแค่รหัสห้อง)

**เพิ่มรายชื่อ** ที่ dashboard การ์ด **รายชื่อผู้เรียน** (ต้องกรอกรหัสผู้สอนแล้วกด "โหลดข้อมูล" ก่อน)
| วิธี | ทำอย่างไร |
|---|---|
| นำเข้าจากลิงก์ | วางลิงก์ Google Sheets แล้วกด **นำเข้าจากลิงก์** (ต้องแชร์ให้บัญชีเจ้าของสคริปต์เปิดได้ · ลิงก์ที่มี `#gid=` จะอ่านแท็บนั้น) |
| นำเข้าจากไฟล์ | เลือกไฟล์ `.csv` `.tsv` `.xlsx` แล้วกด **นำเข้าจากไฟล์** (xlsx โหลดตัวอ่านจากอินเทอร์เน็ต ถ้าไม่ได้ให้บันทึกเป็น CSV) |
| เพิ่มทีละคน | กรอกชื่อ รหัส อีเมล แล้วกด **เพิ่มทีละคน** |
- ไฟล์ต้องมีคอลัมน์อีเมล ระบบจับหัว อีเมล/Email · ชื่อ · รหัส/เลขที่/ลำดับ · สถานะ ให้เอง ถ้าไม่มีหัวจะดูจากคอลัมน์ที่เป็นอีเมล
- อีเมลซ้ำ (ไม่สนตัวพิมพ์) ไม่เพิ่มซ้ำ แต่แก้ชื่อ/รหัส/สถานะตามไฟล์ใหม่ ข้ามแถวที่อีเมลไม่ถูกต้อง รับได้ครั้งละไม่เกิน 1,000 แถว
- แผ่น **รายชื่อ** คอลัมน์ `รหัสผู้เรียน | ชื่อ-นามสกุล | อีเมล Google | สถานะ` · พิมพ์ `ระงับ` ในสถานะเพื่อปิดสิทธิ์รายคน · ถ้าตั้ง `ROSTER_SHEET_ID` (รายชื่ออยู่ไฟล์อื่น) ปุ่มนำเข้าใช้ไม่ได้ ให้แก้ในไฟล์นั้น
- แผ่น Submissions ใช้อีเมลที่ยืนยันแล้วบันทึกในคอลัมน์ "Google (ยืนยันแล้ว)" `ใบงานของฉัน` ค้นจากอีเมลนี้

## 6. แก้รุ่นอุปกรณ์
(เฉพาะ admin ที่กรอกรหัส · บัญชีครูเห็นข้อความ "แก้ ลบ หรือนำเข้ารุ่นอุปกรณ์ไม่ได้")
- เมนู 02 → **ปลดล็อกผู้สอน** (กรอก TEACHER_CODE) หรือเข้าโหมดผู้สอน แล้วเพิ่ม แก้ไข ลบ นำเข้า (PDF / JSON / CSV) ได้
- การแก้ในหน้าเว็บมีผลเฉพาะเบราว์เซอร์นั้น รุ่นที่ต้องการให้ทุกเครื่องเห็น ใส่ใน `BUILTIN` ของ `js/catalog.js` แล้ว build + push

## 7. แบบทดสอบ Google Form
`apps-script/QuizForm.gs` สร้างแบบทดสอบจากคำถามเมนู 00 (วันเสาร์ หัวข้อ 01–07, วันอาทิตย์ 08–15 วันละ 20 ข้อ มีเฉลย) · script.google.com → New project → วางไฟล์ → Run `createBothQuizzes` · Pre/Post-test: `createAllPrePost` · แก้คำถามใน `js/basics.js` แล้วต้องสร้างฟอร์มใหม่

## 8. อัปเดตเว็บ
แก้ไฟล์ต้นทาง → `python3 build.py` → commit + push → GitHub Pages อัปเดตภายในไม่กี่นาที หน้าเว็บบนมือถือจะโหลดเวอร์ชันใหม่เอง

## 9. ข้อมูลที่เก็บ
หนึ่งแถวต่อการกดส่งงาน: ชื่อ รหัส รหัสห้อง เวลา ใบงาน ผลตามเกณฑ์ คำตอบ ผลตรวจการต่อสาย รุ่นอุปกรณ์ ตัวเลขสรุปจำลอง และภาพ ไม่เก็บทุกการลากสาย · แจ้งผู้เรียนว่าเก็บอะไร และลบชีตเมื่อจบรุ่น

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| หัวคอลัมน์ใน Submissions เป็นชื่อเก่าหรือสั้นกว่าปัจจุบัน | วาง `Code.gs` ล่าสุด + Deploy → New version แล้วใช้เมนู **⚡ ระบบโซลาร์ (ผู้สอน) → ซ่อมหัวคอลัมน์ Submissions** (หรือรอจนมีคนส่งงาน / เปิด dashboard) |
| เมนูใหม่ไม่ขึ้นในตาราง dashboard | วาง `Code.gs` ล่าสุด แล้ว Deploy → New version |
| ผู้เรียนส่งงานไม่ได้ | ใบงานปิดรับ · รหัสห้องผิด (โหมดเดิม) · รายชื่อไม่ตรงหรือถูกระงับ |
| ผู้เรียนเข้าด้วย Google แล้วขึ้นว่าอีเมลไม่อยู่ในรายชื่อ | ตรวจว่าอีเมลในแผ่น "รายชื่อ" ตรงกับบัญชี Google ที่ใช้ (ไม่สนตัวพิมพ์เล็กใหญ่) และสถานะไม่ใช่ `ระงับ` |
| ไม่เห็นปุ่ม Google บนแถบด้านบน | ยังไม่ได้ใส่ `GOOGLE_CLIENT_ID` ใน `js/config.js` (build + push) หรือ Authorized JavaScript origins ไม่ตรงโดเมนเว็บ |
| นำเข้ารายชื่อจากลิงก์ไม่ได้ | แชร์ไฟล์ให้บัญชีเจ้าของสคริปต์ หรือใช้ปุ่มนำเข้าจากไฟล์ |
| ปุ่มส่งงานปิดอยู่ | ยังไม่ได้ใส่ `SUBMIT_URL` ใน `js/config.js` |
| ครูเข้าได้แต่นำเข้ารายชื่อหรือแก้รุ่นอุปกรณ์ไม่ได้ | เป็นไปตามสิทธิ์ของบัญชีครู ให้ admin ทำแทน |
| ครูกด Google แล้วเข้าเป็นผู้เรียน หรือเข้าไม่ได้ | ตรวจอีเมลในแผ่น "ครู" ว่าตรงกับบัญชี Google ที่ใช้ (ไม่สนตัวพิมพ์เล็ก/ใหญ่) สถานะไม่ใช่ "ปิด" และตั้ง `GOOGLE_CLIENT_ID` แล้ว |
| dashboard แจ้งรหัสผู้สอนไม่ถูกต้อง | ตรวจ `TEACHER_CODE` ใน Script properties |
| ไม่มีภาพงานส่ง | ยังไม่ได้ตั้ง `DRIVE_FOLDER_ID` หรือใบงานตั้งภาพเป็น `none` |
