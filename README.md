# solar-pv-simulator

จำลองระบบโซลาร์เซลล์ (แผง LONGi Hi-MO X10 650 W, อินเวอร์เตอร์ Solis 6K และรุ่นอื่นที่นำเข้าได้) เปิด `index.html` ในเบราว์เซอร์ได้ทันที

## แท็บ
0. **แบบฝึกพื้นฐาน (เมนู 00, เมนูเริ่มต้น)**: 15 หัวข้อแบบ dropdown ตามกิจกรรมที่ 2 แต่ละหัวข้อมีสรุป แบบจำลองเล็ก (บางหัวข้อมีภารกิจ) และคำถามตรวจทันที ใช้แผงตัวอย่าง 550 W ของเมนูนี้เอง ไม่อิงอุปกรณ์ในเมนูอื่น (`js/basics.js`) ส่งผลด้วยใบงาน W00 เกณฑ์ `basics_done>=15`
1. **อุปกรณ์**: คลังรุ่นแผง อินเวอร์เตอร์ แบต เพิ่มเองหรือนำเข้า JSON / CSV
2. **ต่อสาย**: ลากสาย + / − ทดสอบอนุกรม ขนาน ตรวจชอต
3. **จำลองแผง**: กำลังผลิตทั้งวันตามพิกัด Plus Code มุมเอียง และทิศ
4. **จำลองโหลด**: รายการเครื่องใช้ไฟฟ้าและช่วงเวลา
5. **จำลองการไหลของไฟ**: On-grid / Hybrid / Off-grid พร้อมแบตและไฟดับ
6. **จำลองระบบ 4 แบบ**: เทียบ On-grid / Off-grid / Hybrid off-grid / Hybrid on/off-grid วันเดียวกัน ภาพการไหลของไฟตามเวลา กราฟทั้งวัน ตารางเทียบ ค่าไฟ · เปิดเมฆ เงาต้นไม้ และเงาตึกได้ในแท็บนี้ (ใช้ค่าร่วมกับแท็บจำลองเหตุการณ์)
7. **ส่งงาน**: กรอกชื่อ (หรือ Google Sign-in) ส่งผลสรุปไป Google Sheets ของผู้สอน และสร้างภาพรายงาน PNG ตั้งค่าตาม `apps-script/README.md`
8. **อ่าน log Huawei (เมนู 15)**: เฉพาะผู้เรียนที่ลงชื่อแล้วและผู้สอน ดูหัวข้อด้านล่าง
9. **สายไฟและเบรกเกอร์ (เมนู 06)**: เลือกขนาดสาย เบรกเกอร์ ฟิวส์ สายดิน แรงดันตก ท่อ ทั้ง AC และ DC ดูหัวข้อด้านล่าง
10. **Solis Commissioning (เมนู 13)**: ฝึกติดตั้งและตั้งค่า Solis S6-EH1P6K-L-PLUS ตามคู่มือผู้ผลิต ผู้สอนเปิด/ปิดเมนูนี้เอง ดูหัวข้อด้านล่าง
11. **แบต LiFePO4 + JK-BMS (เมนู 14)**: จัดวางเซลล์ 280/314 Ah ลงตู้ ต่อบัสบาร์ 4S/8S/16S ต่อสายและตั้งค่า JK-BMS ขนานแบต ผู้สอนเปิด/ปิดเมนูนี้เอง ดูหัวข้อด้านล่าง

## เมนูแบบกลุ่ม
แถบเมนูจัดเป็น 4 กลุ่มที่ยุบ/ขยายได้ + ปุ่มส่งงาน: **เริ่มต้น** (00–01) · **อุปกรณ์และต่อสาย** (02–06) · **ออกแบบและจำลอง** (07–12) · **ติดตั้งตามรุ่นจริง** (13–15) · **ส่งงาน** (16) เลขเมนูเรียงตามกลุ่ม (จัดใหม่ ต.ค. 2569: เดิม 14→01, 01–03→02–04, 10→05, 13→06, 04–09→07–12, 15→13, 16→14, 12→15, 11→16) ใบงานและสิทธิ์อ้างอิงรหัสเมนู ไม่ใช่เลข จึงไม่กระทบ กลุ่มที่มีเมนูปัจจุบันเปิดเอง กลุ่มที่ไม่มีเมนูเปิดให้ผู้ใช้คนนั้นจะซ่อน บนมือถือเหลือปุ่มเดียว "☰ ชื่อเมนูปัจจุบัน" แตะเพื่อเปิดรายการ รหัสเมนูและสิทธิ์ในแผ่น "เมนู" ใช้ของเดิม (`app.html`, `navSync()` ใน `js/app.js`)

## โครงสร้าง
`css/` `js/` (config, catalog, model, engine, wiring, solar, loads, backup, systems, submit, ctx, app) · `apps-script/` ตัวรับงานฝั่ง Google Sheets · `app.html` · `build.py` · `dist/` ไฟล์รวมหน้าเดียว · `archive/` เวอร์ชันเก่า

รัน `python3 build.py` เพื่อสร้าง `index.html` และ `dist/pv-wiring-sim.html` ใหม่

ค่ารุ่นที่ระบุ "ค่าสมมติ" ไม่ใช่ข้อมูลจริงของผู้ผลิต ตรวจกับดาต้าชีตก่อนใช้งานจริง ผลจำลองเป็นการประมาณเพื่อการเรียนรู้

## นำเข้าข้อมูลจาก PDF datasheet
แท็บ "อุปกรณ์" → "นำเข้าจาก PDF" เลือกไฟล์ datasheet ของแผง อินเวอร์เตอร์ หรือแบต ระบบอ่านข้อความในเบราว์เซอร์ (ไม่อัปโหลด) แล้วแสดงฟอร์มให้ตรวจ/แก้ก่อนเพิ่มเข้าแคตตาล็อก
ใช้ได้กับ PDF ที่มีข้อความ (ไม่ใช่ภาพสแกน) ไลบรารีอ่าน PDF (pdf.js 3.11.174, Apache-2.0) อยู่ในโฟลเดอร์ `vendor/` ถ้าเปิดไฟล์เดี่ยว `dist/pv-wiring-sim.html` จะโหลดจาก CDN จึงต้องมีอินเทอร์เน็ต
PDF ที่เป็นภาพสแกน (เช่น datasheet ที่บันทึกเป็นภาพ) จะอ่านด้วย OCR (tesseract.js, ภาษาอังกฤษ) อัตโนมัติ ไฟล์ OCR อยู่ใน `vendor/ocr/` (~10 MB) ตัวเลขจาก OCR อาจเพี้ยน ต้องตรวจในฟอร์มก่อนเพิ่ม ถ้า OCR ใช้ไม่ได้ ให้คัดลอกตารางสเปกไปวางในช่อง "วางข้อความจาก datasheet"

## ระบบ 3 เฟส
- อินเวอร์เตอร์มีช่อง "ระบบไฟ AC" (1 / 3 เฟส), "จ่ายไฟแต่ละเฟสไม่เท่ากันได้" และ "พอร์ต Backup" (1 / 3 เฟส)
- เลือกอินเวอร์เตอร์ 3 เฟส แท็บ "ต่อสาย AC" จะเปลี่ยนเป็นผัง L1 L2 L3 N PE พร้อมสมาร์ทมิเตอร์ 3 เฟส (RS485) สายของผัง 1 เฟสและ 3 เฟสเก็บแยกกัน
- ตรวจ: ต่อข้ามเฟส, ชอตระหว่างเฟส, ไฟไม่ครบ 3 เฟส, มิเตอร์วัดไม่ครบทุกเฟส, ต่ออินเวอร์เตอร์ก่อนมิเตอร์, Backup ย้อนเข้ากริด
- แท็บ "จำลองโหลด" กำหนดเฟสให้แต่ละโหลด (L1 / L2 / L3 / 3 เฟส) ตาราง "มิเตอร์ 3 เฟส" แสดงโหลด กำลังอินเวอร์เตอร์ และซื้อ/ขายรายเฟส ณ เวลาที่เลือก กับยอดทั้งวันแบบนับแยกรายเฟสเทียบนับสุทธิ

## แบตตามอินเวอร์เตอร์
เลือกอินเวอร์เตอร์ Huawei แบบ Hybrid ระบบจะเปลี่ยนแบตเป็น LUNA2000 ให้เอง (เลือกอินเวอร์เตอร์ยี่ห้ออื่นจะกลับไปใช้แบตเดิม) รายการแบตในช่องเลือกจะแสดงเฉพาะรุ่นที่ใช้ด้วยกันได้
LUNA2000 ทำงาน 450 V กับอินเวอร์เตอร์ 1 เฟส และ 600 V กับ 3 เฟส ต่ออนุกรมไม่ได้ ขนานได้ 2 ชุด (power module ละ 5 kW, รวมสูงสุด 30 kWh)

## ผังขั้วตามรุ่น Huawei
เลือกอินเวอร์เตอร์ Huawei แท็บ "ต่อสาย AC" จะใช้ชื่อขั้วตามคู่มือ LUNA2000: แบตต่อ BAT+ / BAT− และสายสัญญาณ COM 4 เส้น Enable+ → EN, Enable− → GND, 485A → 485A2, 485B → 485B2 สมาร์ทมิเตอร์ (DDSU666-H 1 เฟส / DTSU666-H 3 เฟส) ต่อ RS485A/B → 485A1/485B1 ไม่มีขั้ว CT และพอร์ต GEN
ระบบตรวจ Enable สลับ, RS485 แบตสลับ, ต่อ RS485 แบตเข้าพอร์ตมิเตอร์ (หรือกลับกัน) และไม่ได้ต่อสายสัญญาณแบต

## ไฟเข้าบ้าน 3 เฟส กับอินเวอร์เตอร์ 1 เฟส
แท็บ "ต่อสาย AC" → ตั้งค่า "ไฟเข้าบ้านจากการไฟฟ้า" เป็น 3 เฟส กริด มิเตอร์ และตู้เมนจะเป็น L1 L2 L3 N PE ส่วนอินเวอร์เตอร์ 1 เฟสต่อ GRID L เข้าเฟสใดเฟสหนึ่ง ตาราง "มิเตอร์ 3 เฟส" จะแสดงว่าไฟจากแผงลงเฉพาะเฟสนั้น

## แท็บ 05 ไซต์และเงา (Shadow & Orientation)
วางบ้าน (หลังคาจั่ว/แบน) ต้นไม้ ตึกข้างเคียง และโซน (ลานซักล้าง สระ สวน ที่จอดรถ ห้องนอน ห้องนั่งเล่น ครัว) บนผัง ลากย้าย แก้ขนาด หมุนได้
- Sun Path ทั้งปีตามพิกัดในแท็บจำลองแผง · เงา ณ วันและเวลา (เล่นเป็นภาพเคลื่อนไหวได้) · แผนที่ชั่วโมงแดด (วัน/ฤดู/ทั้งปี × ทั้งวัน/เช้า/บ่าย/บ่ายแรง)
- ตารางโซน (ห้องวัดที่ผนังภายนอกของห้อง โซนนอกบ้านวัดที่พื้น) · ผนังบ้านแต่ละทิศ · เงาบังข้างบ้านและเงาจากข้างเคียง
- วางแผงโซลาร์บนหลังคาได้ (+ แผงโซลาร์: ความสูง ต่อเข้า MPPT) ตาราง "เงาบนแผง" บอกชั่วโมงที่ถูกบัง
- ติ๊ก "ใช้เงาจากผังไซต์" (แท็บ 04, 08 หรือ 09 ค่าเดียวกัน) แล้วกำลังผลิตในแท็บ 04, 07, 08, 09 คิดเงาจากต้นไม้และตึกในผังแทนต้นไม้/ตึกแบบเดี่ยว
- ผลสรุปผังและโซนแนบไปกับงานที่ส่ง (คอลัมน์ "ไซต์และเงา" ในชีต ต้องวาง Code.gs ล่าสุดและ Deploy → New version)

## เมนู 15 อ่าน log อินเวอร์เตอร์ Huawei
นำเข้าไฟล์ที่ส่งออกจาก FusionSolar / แอป SUN2000 / SmartLogger (CSV, XLSX, XLS หลายไฟล์พร้อมกันได้) อ่านในเบราว์เซอร์ ไม่อัปโหลด ไม่บันทึกไปกับโปรเจ็ค (`js/hwlog.js`)
- ชนิดข้อมูลเดาจากหัวคอลัมน์และช่วงเวลา: รายช่วงเวลาในวัน (5 นาที ฯลฯ) · รายงานรายวัน/รายเดือน · รายการแจ้งเตือน (alarm) แก้ชนิดและการจับคู่คอลัมน์/หน่วยได้ในส่วน "ตรวจคอลัมน์"
- รายช่วงเวลา: เลือกวัน ดูพลังงานที่ผลิต kWh/kWp กำลังสูงสุด ช่วงที่ผลิตไฟ แรงดัน/กระแสแต่ละสตริง แรงดันกริด SOC แบต อุณหภูมิ ขาย/ซื้อไฟ และข้อสังเกตอัตโนมัติ (clipping, ข้อมูลขาด, สตริงไม่เท่ากัน/เงาตอนเช้า, แรงดันกริดนอก 207–253 V, กริดหาย, อุณหภูมิสูง, SOC ต่ำ) ช่วงที่มีแจ้งเตือนแสดงเป็นแถบสีในกราฟ ส่งออก CSV ที่จัดเรียงแล้วได้
- แจ้งเตือน: ตารางพร้อมระยะเวลาและแนวทางตรวจเบื้องต้นของรหัสที่พบบ่อย (2001, 2011–2015, 2032–2038, 2051, 2061–2068 ฯลฯ) ตรวจกับคู่มือรุ่นนั้นเสมอ
- มีข้อมูลตัวอย่าง (สังเคราะห์) และไฟล์ตัวอย่าง CSV ให้ฝึกนำเข้า
- สิทธิ์: ผู้เยี่ยมชมไม่เห็นเมนูนี้เสมอ (รวมทั้งตอนไม่มี `SUBMIT_URL`) ผู้เรียนใช้ได้ตามสถานะในแผ่น "เมนู" (ค่าเริ่ม "เปิด") ผู้สอนปิดหรือตั้งดูอย่างเดียวได้ที่ dashboard ออกจากระบบแล้วข้อมูลที่นำเข้าถูกล้าง
- ไฟล์ Excel อ่านด้วย SheetJS 0.18.5 (Apache-2.0) ใน `vendor/xlsx.full.min.js` (ไฟล์เดี่ยวใน `dist/` โหลดจาก CDN)

## เมนู 06 สายไฟและเบรกเกอร์
เครื่องคำนวณที่เขียนขึ้นเองสำหรับซิมูเลเตอร์นี้ (`js/cable.js`) ทำงานในเบราว์เซอร์ บันทึกค่าไปกับโปรเจ็ค มี 5 หน้าย่อย
- **AC: สาย + เบรกเกอร์**: ขาออกอินเวอร์เตอร์ที่เลือกในเมนู 02 (คิดกระแสที่ 220 / 380 V × 1.25) หรือโหลดทั่วไป (kW / kVA / A, 1 / 3 เฟส) → เบรกเกอร์ (MCB / MCCB, curve, ขั้ว, Icu), RCD, สายเฟส N PE, แรงดันตก, ท่อ / รางเดินสาย และตารางเทียบทุกขนาดสาย
- **DC: สตริงแผง**: ดึงค่าแผงและจำนวนอนุกรม/ขนานจากเมนู 02–03 → Voc สูงสุดตอนเย็น, ฟิวส์สตริง gPV (เมื่อ (Np−1)·Isc เกินพิกัดฟิวส์ของแผง), สาย PV สตริงและสายรวม, เบรกเกอร์ / สวิตช์ DC, SPD
- **DC: แบตเตอรี่**: ดึงแบตและอินเวอร์เตอร์จากเมนู 02 → กระแสสูงสุด, ฟิวส์ class T / เบรกเกอร์ DC, พิกัดตัดกระแส, สายแบต, แรงดันตก
- **เลือกเบรกเกอร์ AC / DC**: หาพิกัดเบรกเกอร์เร็ว ๆ จาก kW หรือ A (AC) หรือจาก PV / แบต / โหลด DC 12–48 V
- **ตารางอ้างอิง**: พิกัดกระแสสาย PVC / XLPE / PV, ตัวคูณอุณหภูมิ, ตัวคูณจัดกลุ่ม และสูตรที่ใช้

ค่าอ้างอิงตามวิธีติดตั้งของ IEC 60364-5-52 (ทองแดง), EN 50618 (สายโซลาร์), สายดินตาม IEC 60364-5-54 ตาราง 54.2 และหลัก IEC 62548 แบบย่อ เป็นการออกแบบเบื้องต้นเพื่อการเรียนรู้ ต้องตรวจกับ วสท. ฉบับที่ใช้บังคับ ข้อกำหนดการไฟฟ้า และดาต้าชีตผู้ผลิตก่อนใช้งานจริง
สิทธิ์: แผ่น "เมนู" ตั้งค่าเริ่มเมนูนี้เป็น "เปิด" ให้ผู้เรียน (ต้องวาง `Code.gs` ล่าสุดแล้ว Deploy → New version) ผู้เยี่ยมชมไม่เห็นจนกว่าผู้สอนจะติ๊กที่ dashboard

## เมนู 01 คลังความรู้
บทความอ่านประกอบเมนูอื่น ค้นหาและกรองตามหมวดได้ ลิงก์ตรงไปบทความได้ด้วย `#library/<id>` เช่น `#library/mcb-curves` (`js/library.js`)
- บทความแรก: เคิร์ฟการทริปของ MCB (B, C, D, K, Z) ตาราง magnetic/thermal (IEC 60898-1 / 60947-2) กราฟเวลา-กระแสแบบ log ที่เลือก curve ได้ สลับ AC/DC เครื่องมือเลือก curve จากกระแสกระชากของโหลดและกระแสลัดวงจรปลายสาย การใช้กับ DC ในระบบโซลาร์ ป้ายเบรกเกอร์ ข้อผิดพลาดที่พบบ่อย และคำถามทบทวน 4 ข้อ
- บทความที่ 2: ดูให้ออกว่าเบรกเกอร์ตัวไหนเป็น RCD (RCCB / RCBO) หรือ MCB (`js/kb_rcd.js`, ลิงก์ `#library/rcd-vs-mcb`) จุดสังเกต 3 อย่าง ตารางเทียบ มาตรฐาน IEC / มอก. วงจรที่ วสท. พ.ศ. 2564 กำหนดให้มี RCD 30 mA การใช้ในระบบโซลาร์ และแบบฝึกอ่านฉลาก 5 ข้อ
- เมนู 06 หน้า "เลือกเบรกเกอร์" มีลิงก์ "อ่านเรื่อง curve" มาที่บทความนี้ ลิงก์จากหน้าอื่นใช้ `<a data-kblink="<id>">`
- เพิ่มบทความ: เพิ่ม `kbAdd({id, cat, title, summary, tags, upd, body, init, related, src})` ใน `js/library.js` (หรือไฟล์ใหม่ที่ใส่ต่อจาก `'library'` ใน `build.py`) แล้ว `python3 build.py` หมวดอยู่ใน `KB_CATS` หมวดที่ยังไม่มีบทความจะไม่แสดง
- สิทธิ์: ค่าเริ่มต้นในแผ่น "เมนู" = เปิดให้ผู้เรียน ผู้เยี่ยมชมเห็นถ้าผู้สอนติ๊ก

## เมนู 13 Solis Commissioning (Hybrid / On-grid / Off-grid / AC coupling)
จำลองการติดตั้งและ commissioning อินเวอร์เตอร์ Solis S6-EH1P6K-L-PLUS อ้างอิงคู่มือ S6-EH1P(3-8)K-L-PLUS User Manual V1.3 (04/2026) ใน Drive `PV Datasheets/01 อินเวอร์เตอร์/Solis` (`js/solis.js`)
- **ระบบ 4 แบบ** แต่ละแบบมีใบสั่งงาน: On-grid ไม่มีแบต (PEA ขายไฟ ≤ 5 kW) · Hybrid กริด + Backup (PEA ห้ามขายไฟ สำรองแบต ≥ 30%) · Off-grid (ไม่มี CT/มิเตอร์) · AC coupling (อินเวอร์เตอร์ออนกริดเดิม 3 kW ที่พอร์ต GEN, MEA)
- **1 ใบสั่งงานและการต่อพอร์ต**: เลือกสิ่งที่ต่อเข้า PV1/PV2, BAT, AC-GRID, AC-BACKUP, AC-GEN, CT (ตำแหน่ง ทิศลูกศร สายขาว/ดำ), BMS (CAN), METER พร้อมผังระบบ ตรวจข้อห้ามตามคู่มือ เช่น ห้ามต่อ BACKUP เข้ากริด
- **2 ตรวจวัดและ Power ON/OFF**: เช็กลิสต์ 5.1, สวิตช์แบต / DC switch / OCPD / เบรกเกอร์ Backup, มัลติมิเตอร์ (PV, BAT, L–N, L–PE, N–PE, Backup, ความต่อเนื่อง PE, ตรวจ CT และหัว CAN ด้วยตา) และ LED POWER / OPERATION / ALARM ระบบตรวจลำดับตามข้อ 5.2 (วัด PV ก่อนเปิด DC switch, วัด AC แล้วปิด OCPD, เปิด DC ก่อน OCPD, เปิด Backup หลัง commissioning) และลำดับปิดเครื่องตามข้อ 5.3
- **3 หน้าจอเครื่อง**: จอ 7 นิ้วพร้อมปุ่ม ESC ▲ ▼ ENTER: Quick Setting 5 ขั้น (เวลา → Meter → Grid code → Storage mode → Battery) แล้วเข้า HOME: Plant / Alarm Information, System Setting (Storage Mode + Time of use, Battery, Smart Port, Grid Port, Parallel, Basic) ตามผัง 5.4.2
- **4 แดชบอร์ด**: หน้า Devices Status (แผง แบต กริด โหลดกริด โหลด Backup AC coupled) เลื่อนเวลา/เล่น ตั้งไฟดับ เมฆ และโหลด Backup เพิ่ม กราฟทั้งวันและสรุป kWh ผลจำลองเปลี่ยนตามการตั้งค่าจริง เช่น Self-use / Selling first / Off grid, Allow export, Max export, Battery reserve, Over discharge, Allow grid charging, Peak shaving, Smart Port (AC couple input ใช้ Freq-Watt ลดกำลังเครื่องเดิมตอนไฟดับ)
- **5 โจทย์หาข้อผิดพลาด**: สุ่มความผิดพลาดหน้างาน 2 จุด (CT กลับทิศ/สายสลับ/หลุด, PV เกิน 500 V, PV2 กลับขั้ว, ฟิวส์แบตขาด, CAN pin ไม่ตรง, BACKUP ต่อเข้าตู้เมน, L/N สลับ, ไม่ต่อ PE) ให้ผู้เรียนหาด้วยการวัดและ alarm ผู้สอนกำหนดโจทย์เองได้ (ส่วนนี้ผู้เรียนไม่เห็น)
- Alarm ที่จำลอง: OV-DC01, OV-Vbackup, NO-Battery, CAN Fail, BatName-FAIL, MET-SLT-Fail, NO-Grid, Over-Load, OV-Vbatt (ชื่อตามตาราง 7.1 / FAQ)
- **สิทธิ์**: แผ่น "เมนู" ตั้งค่าเริ่มเมนูนี้เป็น "ปิด" ผู้เรียนและผู้เยี่ยมชมไม่เห็นจนกว่าผู้สอนเลือก "เปิด" ที่ dashboard (ต้องวาง `Code.gs` ล่าสุดแล้ว Deploy → New version) ถ้าชีตยังไม่มีแถวนี้ หน้าเว็บก็ซ่อนเมนูจากผู้เรียนไว้ก่อน
- **ใบงาน W8** (ค่าเริ่ม = ปิด): เกณฑ์ `solis_done>=1` (ทำระบบใดระบบหนึ่งผ่านครบ) และ `solis_diag>=1` (หาข้อผิดพลาดถูก 1 โจทย์)

## เมนู 14 แบต LiFePO4 + JK-BMS
หน้าจำลองอยู่ใน `lfp.html` (หน้าเดี่ยว เปิดตรงได้) แสดงในเมนู 14 ผ่าน iframe ที่โหลดเมื่อเปิดเมนูครั้งแรก (`js/lfp.js`) ไฟล์รวม `dist/` ฝังหน้าไว้ใน `LFP_DOC` · อ้างอิงคู่มือ JK-PB1A16S/PB2A16S V24.0.1, JK ESS BMS V15, JK-B2A24S / B2A16S-TH, JK-BLMK-5A และ JKBMS Installation Guide
- **1 จัดวางลงกล่อง**: เริ่มด้วยเซลล์กระจายแบบสุ่ม (ลำดับ ทิศ 0/90/180/270° และตำแหน่งรอบตู้หรือหลวมในตู้ ไม่เรียงเป็นระเบียบ) ทุกครั้งที่เปิดหน้า ยกเว้นเริ่มต่อบัสบาร์แล้ว (กรอบประสีเหลือง = ยังไม่วางลงตู้) ผู้เรียนลากเข้าช่องเอง เลือกเซลล์แล้วมีปุ่มหมุน ⟳ และกลับขั้ว ± ที่ตัวเซลล์ เลขเซลล์ไม่กลับหัว ( ปุ่ม "เรียงให้ดู (เฉลย)" วางพร้อมต่อ) ตู้ตั้งแบบ WH Energy (ช่องเซลล์กว้าง 350 × ลึก 210 × สูง 684 มม. + ช่อง BMS ด้านบน 150 มม.) เซลล์นอนตะแคงหันขั้วออกประตู 2 คอลัมน์ × 8 ชั้น หรือกล่องนอน/เซลล์ตั้งหลายแบบ ลาก หมุน 90° กลับขั้ว 180° มุมมองหน้า/บน ด้านข้าง และไอโซเมตริก ตรวจล้นกล่อง ทับกัน และความลึก
- **2 ต่อบัสบาร์ & สาย BMS**: คลิกขั้ววางบัสบาร์ ตรวจอนุกรม กลับขั้ว ลัดวงจร · ชุดสาย B−, B0–B16, BAT+, P−, สายบวกหลัก, NTC · มัลติมิเตอร์ลากโพรบแดง/ดำไปแตะขั้วหรือขา BMS · เสียบปลั๊ก sense ขณะสายผิด = BMS เสียหาย · กดเปิด (Activate)
- **3 ตั้งค่า JK-BMS & ทดสอบ**: หน้าจอแอป (สถานะ / ตั้งค่า รหัส 123456 / ควบคุม) ค่าโรงงาน LiFePO4 ตามตาราง 4.2 (ตั้งไว้ 16 เซลล์ 280 Ah ให้ผู้เรียนแก้) จำลองชาร์จ/จ่าย บาลานซ์ OVP/UVP กระแสเกิน อุณหภูมิ ลัดวงจร กราฟ และบันทึกเหตุการณ์
- **4 ขนานแบต & อินเวอร์เตอร์**: 1–8 แพ็ก ตั้ง DIP (Master = 0) ต่อ RS485-2 พ่วง CAN/RS485-1 จาก Master ไปอินเวอร์เตอร์ ต่อสายไฟเข้าบัส เปิดเบรกเกอร์ ดูกระแสไหลหากันตาม SOC ฟังก์ชันจำกัดกระแส 10A ขั้นตอนตั้งค่า Deye / Growatt / Voltronic / SRNE
- **สิทธิ์**: แผ่น "เมนู" ค่าเริ่ม = "ปิด" ผู้เรียนและผู้เยี่ยมชมไม่เห็นจนกว่าผู้สอนเลือก "เปิด" ที่ dashboard (วาง `Code.gs` ล่าสุดแล้ว Deploy → New version เพื่อให้มีแถวนี้) ถ้าชีตยังไม่มีแถวนี้ หน้าเว็บก็ซ่อนเมนูจากผู้เรียนไว้ก่อน
- ขนาดเซลล์ ค่า IR และ JK-B2A8S20P (สำหรับ 4S) ไม่ได้มาจากเอกสารแนบ เป็นค่าประมาณ ตรวจกับดาต้าชีตก่อนใช้งานจริง
