# solar-pv-simulator

จำลองระบบโซลาร์เซลล์ (แผง LONGi Hi-MO X10 650 W, อินเวอร์เตอร์ Solis 6K และรุ่นอื่นที่นำเข้าได้) เปิด `index.html` ในเบราว์เซอร์ได้ทันที

## แท็บ
1. **อุปกรณ์**: คลังรุ่นแผง อินเวอร์เตอร์ แบต เพิ่มเองหรือนำเข้า JSON / CSV
2. **ต่อสาย**: ลากสาย + / − ทดสอบอนุกรม ขนาน ตรวจชอต
3. **จำลองแผง**: กำลังผลิตทั้งวันตามพิกัด Plus Code มุมเอียง และทิศ
4. **จำลองโหลด**: รายการเครื่องใช้ไฟฟ้าและช่วงเวลา
5. **จำลอง Backup**: On-grid / Hybrid / Off-grid พร้อมแบตและไฟดับ
6. **ส่งงาน**: กรอกชื่อ (หรือ Google Sign-in) ส่งผลสรุปไป Google Sheets ของผู้สอน และสร้างภาพรายงาน PNG ตั้งค่าตาม `apps-script/README.md`

## โครงสร้าง
`css/` `js/` (config, catalog, model, engine, wiring, solar, loads, backup, submit, app) · `apps-script/` ตัวรับงานฝั่ง Google Sheets · `app.html` · `build.py` · `dist/` ไฟล์รวมหน้าเดียว · `archive/` เวอร์ชันเก่า

รัน `python3 build.py` เพื่อสร้าง `index.html` และ `dist/pv-wiring-sim.html` ใหม่

ค่ารุ่นที่ระบุ "ค่าสมมติ" ไม่ใช่ข้อมูลจริงของผู้ผลิต ตรวจกับดาต้าชีตก่อนใช้งานจริง ผลจำลองเป็นการประมาณเพื่อการเรียนรู้

## นำเข้าข้อมูลจาก PDF datasheet
แท็บ "อุปกรณ์" → "นำเข้าจาก PDF" เลือกไฟล์ datasheet ของแผง อินเวอร์เตอร์ หรือแบต ระบบอ่านข้อความในเบราว์เซอร์ (ไม่อัปโหลด) แล้วแสดงฟอร์มให้ตรวจ/แก้ก่อนเพิ่มเข้าแคตตาล็อก
ใช้ได้กับ PDF ที่มีข้อความ (ไม่ใช่ภาพสแกน) ไลบรารีอ่าน PDF (pdf.js 3.11.174, Apache-2.0) อยู่ในโฟลเดอร์ `vendor/` ถ้าเปิดไฟล์เดี่ยว `dist/pv-wiring-sim.html` จะโหลดจาก CDN จึงต้องมีอินเทอร์เน็ต
PDF ที่เป็นภาพสแกน (เช่น datasheet ที่บันทึกเป็นภาพ) จะอ่านด้วย OCR (tesseract.js, ภาษาอังกฤษ) อัตโนมัติ ไฟล์ OCR อยู่ใน `vendor/ocr/` (~10 MB) ตัวเลขจาก OCR อาจเพี้ยน ต้องตรวจในฟอร์มก่อนเพิ่ม ถ้า OCR ใช้ไม่ได้ ให้คัดลอกตารางสเปกไปวางในช่อง "วางข้อความจาก datasheet"

## ระบบ 3 เฟส
- อินเวอร์เตอร์มีช่อง "ระบบไฟ AC" (1 / 3 เฟส), "จ่ายไฟแต่ละเฟสไม่เท่ากันได้" และ "พอร์ต Backup" (1 / 3 เฟส)
- เลือกอินเวอร์เตอร์ 3 เฟส แท็บ "ต่อสาย AC" จะเปลี่ยนเป็นผัง L1 L2 L3 N PE พร้อมสมาร์ทมิเตอร์ 3 เฟส (RS485) สายของผัง 1 เฟสและ 3 เฟสเก็บแยกกัน
- ตรวจ: ต่อข้ามเฟส, ชอตระหว่างเฟส, ไฟไม่ครบ 3 เฟส, มิเตอร์วัดไม่ครบทุกเฟส, ต่ออินเวอร์เตอร์ก่อนมิเตอร์, Backup ย้อนเข้ากริด
- แท็บ "จำลองโหลด" กำหนดเฟสให้แต่ละโหลด (L1 / L2 / L3 / 3 เฟส) ตาราง "มิเตอร์ 3 เฟส" แสดงโหลด กำลังอินเวอร์เตอร์ และซื้อ/ขายรายเฟส ณ เวลาที่เลือก กับยอดทั้งวันแบบนับแยกรายเฟสเทียบนับสุทธิ

## แบตตามอินเวอร์เตอร์
เลือกอินเวอร์เตอร์ Huawei แบบ Hybrid ระบบจะเปลี่ยนแบตเป็น LUNA2000 ให้เอง (เลือกอินเวอร์เตอร์ยี่ห้ออื่นจะกลับไปใช้แบตเดิม) รายการแบตในช่องเลือกจะแสดงเฉพาะรุ่นที่ใช้ด้วยกันได้
LUNA2000 ทำงาน 450 V กับอินเวอร์เตอร์ 1 เฟส และ 600 V กับ 3 เฟส ต่ออนุกรมไม่ได้ ขนานได้ 2 ชุด (power module ละ 5 kW, รวมสูงสุด 30 kWh)

## ผังขั้วตามรุ่น Huawei
เลือกอินเวอร์เตอร์ Huawei แท็บ "ต่อสาย AC" จะใช้ชื่อขั้วตามคู่มือ LUNA2000: แบตต่อ BAT+ / BAT− และสายสัญญาณ COM 4 เส้น Enable+ → EN, Enable− → GND, 485A → 485A2, 485B → 485B2 สมาร์ทมิเตอร์ (DDSU666-H 1 เฟส / DTSU666-H 3 เฟส) ต่อ RS485A/B → 485A1/485B1 ไม่มีขั้ว CT และพอร์ต GEN
ระบบตรวจ Enable สลับ, RS485 แบตสลับ, ต่อ RS485 แบตเข้าพอร์ตมิเตอร์ (หรือกลับกัน) และไม่ได้ต่อสายสัญญาณแบต

## ไฟเข้าบ้าน 3 เฟส กับอินเวอร์เตอร์ 1 เฟส
แท็บ "ต่อสาย AC" → ตั้งค่า "ไฟเข้าบ้านจากการไฟฟ้า" เป็น 3 เฟส กริด มิเตอร์ และตู้เมนจะเป็น L1 L2 L3 N PE ส่วนอินเวอร์เตอร์ 1 เฟสต่อ GRID L เข้าเฟสใดเฟสหนึ่ง ตาราง "มิเตอร์ 3 เฟส" จะแสดงว่าไฟจากแผงลงเฉพาะเฟสนั้น

## แถบ "ใช้ข้อมูล" ใต้หัวข้อทุกแท็บ
บอกว่าแท็บนั้นกำลังใช้ข้อมูลอะไรจากแท็บไหน (`js/ctx.js`) จุดเขียว = ใช้ข้อมูลจากแท็บอื่น · วงกลมโปร่ง = ค่าสมมติหรือยังไม่เปิดใช้ · สีเหลือง = แท็บต้นทางยังไม่พร้อม แตะชิปที่มีเลขแท็บเพื่อไปแท็บนั้น
